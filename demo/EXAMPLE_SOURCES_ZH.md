## 验收状态的含义

“已实测”只用于留有该份输入的真实网页模型调用、条件审核、识别执行和独立重放记录的例子。只有离线参考 JSON 跑通的，不能标成真实 LLM 通过。没有得到结果的保留“待验收／读取未完成”等实际状态。

材料的未知条件不会因文献发表或示例预期而自动获准。没有现场结果时不显示预先编造的 POINT/PARTIAL。修改原文或材料后视为新任务，旧证书不沿用。

## 与原文答案的实际核对（2026-11-04）

验收须分开三个问题：论文问什么，当前示例问什么，系统实际返回了什么。名称相似、同为 POINT 或数值方向相同，都不能单独证明答案一致。下面没有把合成数据当成论文数据，也没有为取得一致结论追加科学条件。

| 示例 | 原文定位与对应关系 | 当前判断 |
|---|---|---|
| N60 | Aronow–Samii §8 式(16)、推论8.1的原设计条件平均 | 方法形式一致；数据与估计值自建 |
| 疫苗 | Hudgens–Halloran的两阶段接种场景；Aronow–Samii §8的原设计平均目标 | 明示改编；不另加组间无干扰，不称原试验复现 |
| 校园 | Aronow–Samii §8、§10 的手环与间接暴露 | 设计加权目标对应；同一项目学校内比较，不复现表2数值 |
| 农户 | Beaman等 AER 的网络选种场景 | 仅场景启发；混合政策均值不同于原论文的策略效果比较 |
| 观察性学习 | Forastiere等作者稿定理1、式(7) | 调整思路对应；单个对象的有限均值版本，非原文整体ADRF |
| 七网点 PARTIAL | Manski的有效处理和识别集思想 | 项目自建均值模型；原文没有该区间数值 |
| 均值顺序 PARTIAL | Manski的响应限制思想 | 项目约束的是均值；不等于原文逐个响应函数单调性 |
| 后门 | Pearl定理1、式(6) | 本题真实网页已产生同形式的调整公式并通过重放 |
| 前门 | Pearl图3、定理2、式(9) | 本题真实网页已产生前门公式并通过重放 |

**原设计平均的公式核对。** 对每个对象，以 d 表示本人及同伴状态，q 为原分配律：

\[
\bar\mu_i^q(d)=\sum_{t:D_i(t)=d}\frac{q(t)}{\Pr_q(D_i=d)}\mu_i(t).
\]

在本例独立性、一致性与正支持前提下，它等于可观察条件均值。N60、校园和疫苗的保存结果逐项核对了两端、符号、名单及权重。对校园225份、疫苗32份完整安排另作精确枚举，条件权重和为1；这与 [Aronow–Samii 作者终稿 §8](https://arxiv.org/html/1305.6156v3#S8) 的式(16)及推论8.1对应。未采用暴露充分性时，不将它改称与设计无关的局部潜在结果。

疫苗另有两个实质差别：[Hudgens–Halloran 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2600548/)采用组间无干扰；当前没有单独批准这一条件，不能仅由无跨组边推出。当前方向为高覆盖减低覆盖的感染概率，原文疫苗表的获益方向为低减高。要比较须先统一方向、分配策略与组间条件；本轮没有偷偷补条件。

**DAG 公式核对。** 令 X 为处理、Y 为结果、Z 为调整变量或中介，原生后门和前门输出分别为：

\[
p(y\mid do(x))=\sum_z p(y\mid x,z)p(z),
\qquad
p(y\mid do(x))=\sum_z p(z\mid x)\sum_{x'}p(y\mid x',z)p(x').
\]

与 [Pearl原文式(6)、式(9)](https://bayes.cs.ucla.edu/R218-B.pdf)核对时，检查的是求和变量、条件集合和处理值角色，特别保留前门内层的 x' 与干预值 x 的区别。本轮两个真实网页业务均已得到上述形式并通过证书重放；业务目标经过后台模型复核，图、来源和科学声明经过本轮验收核对及页面条件确认。DAG事实阶段尚未使用网络题的第二次模型来源复核，不将二者混称为相同自动审核覆盖。

**PARTIAL 独立核算。** 七网点全启用的六个叶节点均值各为1/2，中心目标均值可在[0,1]变化，因此等权平均 sharp 界限为[3/7,4/7]，与真实网页证书一致。四店均值顺序模型的可行端点分别可取 (m00,m01,m10,m11)=(2/5,2/5,3/5,3/5) 和 (0,2/5,3/5,1)，差值界限[1/5,1]；本轮真实网页输出与这一独立核算一致，证书重放通过。这里没有引用 Manski 来代替本模型的 sharp 证明。

**观察性网络调整。** 本题只评价甲，对共同的两个处理前特征层各按1/2加权；每层比较本人不参加时“朋友有人参加”减“朋友都不参加”的条件结果均值。实际证书给出这四项的加减式，保留固定W，并未按两端各自的特征分布平均。该有限均值模型与[Forastiere等作者稿定理1、式(7)](https://arxiv.org/html/1609.06245v4#S2.SS5)的调整结构对应，条件交换性及目标范围的差别仍如上表。
