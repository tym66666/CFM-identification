description: 在已审核业务目标下读取网络事实；共同定义集中引用，科学声明与总体信息分别保留，不判断识别。
---

1. 先读取study：完整研究名单、网络边、处理与结果编码、结果期间。source_ids引用名单、编码、结果和时期；network_source_ids单独引用网络边、无向关系及名单完整性的原文。study是其他记录使用对象名称和编码的共同定义；exposure是同伴状态的共同定义。其余记录引用自己的直接主张，无须重复粘贴共同定义来源，但不能借定义猜出政策、评价名单、概率、信息范围或科学态度。
2. 按已审核意图保留政策两端、减法方向、评价对象、权重、时期与背景。研究名单不等于评价名单；未说明的安排不能填0。普通期间不变成固定协变量。若合同不能表达原问，保留OTHER或未知及具体原因，不换问题。
3. assignment只写试点实际规则。已说明各自独立抛公平硬币，就保留各单位1/2及独立性；原文只给类别但没给概率时仍为null。目标政策的0/1不是试点概率。随机设计的描述不能代替采用“分配与潜在结果独立”的科学声明。
4. information先判断样本还是总体，再看分布中有哪些变量：每个单位各自的结果与完整安排的分布，用EACH_OUTCOME_WITH_FULL_ASSIGNMENT，即一组P(Y_i,T)；所有结果一起与完整安排的联合分布才用ALL_OUTCOMES_TOGETHER_WITH_FULL_ASSIGNMENT，即P(Y_1,…,Y_n,T)。多个单对象分布不能拼成全部结果联合分布。有限记录或估计值只用FINITE_SAMPLE。明确总体均值按完整安排格子或本人/暴露格子分别填写，不补格子、不补数值、不把均值升级成分布。范围以信息原文为准，不能从研究名单或目标名单默认全覆盖。
5. 科学条件按本次Schema各字段的合同记录。带status的条件分别保留采用、拟采用、拒绝、未定等态度；同段条件可以态度不同。均值顺序的relation使用另一种合同：明确提出采用或拟采用非减关系均记录NONDECREASING，明确不采用为NOT_ASSUMED，尚未决定为UNKNOWN；不另设状态栏，也不把字段没有状态栏的说明填成额外限制。拟采用不等于拒绝或尚未决定。关系和原句引用不授予科学许可，所有声明仍等待独立科学审核。暴露定义不推出均值充分性；不采用不代表反命题成立。
6. 若涉及界和均值顺序，保留其数值尺度、对象、期间和完整安排范围。信息是否列尽、模型是否无额外耦合是两件事；存在顺序或等式时不能声称没有耦合。明确的额外限制放在专门字段或additional_restrictions，不能丢失，也不重复登记。没有数值模型就不捏造bounds。真实缺项或冲突放unresolved。
7. 输出前按当前Schema核对类型、必填字段和直接引用。共同定义必须有自己的充分证据；每条概率、政策、信息及科学声明仍需自己的原文。不得用来源目录、审核、Skill或既有模型答案作事实；只返回完整JSON，不输出推导或自评。
