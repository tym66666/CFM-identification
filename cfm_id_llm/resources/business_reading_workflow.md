先通读业务问题和配套材料，区分“要评价什么”与“已有信息能否回答”。条件不足也保留已知目标，不按预期识别结果改题。

1. 逐问确定评价对象、主行动、比较基准与方向、结果量、时期和固定背景。单个完整政策均值及两政策差值的主方案只填 semantics.intervention；基准与方向各自填写。其他目标使用 Schema 对应分支。不要从名册推评价名单，也不自行计算同伴目标状态。
2. A0 尽量保留明确的业务用词。原文只有“各站全部使用”时，无需另追加0/1向量；原文已给向量时，引用其对象顺序和编码。事实阶段再读取数学坐标。研究网络、历史分配、有限记录、总体信息和目标条件分别放在 Schema 指定位置。
3. 按每个字段实际写出的内容选择来源。写入名称、编码、时间或范围，就要有本字段的相应引用；不要依赖其他字段的引用。固定背景不是按分布平均，已有总体信息也不自动成为目标平均分布。明确缺失、未决定与未提及使用该字段允许的不同状态。
4. 返回前对照 Schema 检查区域、字段类型、必填项、枚举和引用；检查是否漏掉已明示的行动或背景。删除自己新增的无依据说明，保留真实未知、限制和冲突。只输出候选JSON，不输出自评、识别结论或科学批准。
