现场演示时如何解释？

老师看到的不是“填表后算法自动猜答案”，而是同一业务问题在不同研究条件下的正式结果：

原始材料缺总体信息 → 暂不能认证；补足合法合成科学条件 → 正式 Core 可以识别或因零支持拒绝；再额外引入经过明确接受的结构限制 → 某些完整政策可以识别。

研究人员说明：识别不等于估计

这里的 POINT 是总体泛函可识别，绝非现实观测数据的数值估计。UNSUPPORTED 表示当前实现的定理无法认证，不等于一般数学意义上的非识别。本站不调用任何在线 LLM，也不创建假设批准记录。

所有数据仅包含原公开研究题库及预设合成数学方案。离线浏览时展示构建期的 Core 复核快照；需要现场重新计算请启动本机服务。
