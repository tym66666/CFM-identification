# 试点题的独立参考计算

此说明从业务材料和有限均值模型出发，不调用项目求解器。由Codex进行源码和材料对照，尚未由独立人类研究者签审；不能因此假称实验已经通过验收。

点识别题有5个网点，每个网点独立以1/2概率启用，全体启用的完整安排概率是(1/2)^5=1/32。在原文声明的完整向量随机化、一致性及所需总体条件均值可用时，5个对象在该完整安排下的潜在结果均值等于相应观察条件均值；目标是这5项等权平均。该结论依赖原文中的条件，并不是从LLM输出推导条件真实。

部分识别题有7个网点，中心连接6个叶子，历史每次从7个网点中均匀抽3个。总共C(7,3)=35个安排。目标是7个网点全部启用；中心目标签名为自身启用且超过半数邻居启用。中心加上至少4个邻居至少需要5个启用，与历史恰好3个矛盾，故该目标签名支持为零。每个叶子的目标签名（自身与中心均启用）在历史中有支持，且其精确条件均值为1/2。完整均值模型明确给出中心未知均值为[0,1]、没有额外耦合限制，因此7店等权平均的端点为(6×1/2+0)/7=3/7和(6×1/2+1)/7=4/7。

端点可达性：在原文列明的有限均值模型下，把中心未观察的目标签名单元均值分别取0和1，其他单元取与列出的精确均值和[0,1]界一致的值，例如1/2；处理按给定随机规则抽取，结果可由与处理独立的潜在结果构造。两个模型具有相同已列出的观察信息而目标不同，端点都可达到，故区间在该明确模型内为sharp，目标不是点识别。这个结论不适用于额外信息、额外耦合条件或不同模型。
