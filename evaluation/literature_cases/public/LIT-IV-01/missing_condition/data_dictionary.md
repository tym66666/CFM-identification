# 数据字典

## `observed_joint_counts.csv`

| 字段 | 含义 |
|---|---|
| `Z` | 是否获得培训资格，1=有资格，0=无资格 |
| `D` | 是否实际参加培训，1=参加，0=未参加 |
| `Y` | 就业是否改善，1=改善，0=未改善 |
| `count` | 该 \((Z,D,Y)\) 组合的员工人数 |

说明：

- 总人数为 200；
- 这是一张有限样本的联合计数表，不是总体分布；
- 没有个人标识，也没有其他协变量。

## 变量编码

| 变量 | 取值 |
|---|---|
| \(Z\) | 0/1 |
| \(D\) | 0/1 |
| \(Y\) | 0/1 |

## 未提供的材料

- 逐人名单；
- 潜在参与 \(D(1),D(0)\)；
- 潜在结果 \(Y(1),Y(0)\)；
- 总体联合分布或总体条件均值。

这些未提供的内容不能由计数表自动补出。
