# 当前运行与评分口径

## 从业务材料实际运行

使用 `tools.public_input.load_public(case_id, variant)`，只读取公开 manifest 列出的原题与附件，返回网页 Engine 可直接接收的 payload 和文件摘要。不会读取参考答案，也不会生成目标、A4、A5 或审核批准。

```powershell
python -m evaluation.literature_cases.tools.public_input --case-id LIT-NET-04 --output public_payload.json
```

对象表与关系表通过 manifest 的明确角色进入现有网络上传接口。完整性说明引用原协议中的原句，不从边数推断完整性。普通表格附件仍只提取结构信息，不能因此变成精确总体分布。当前统一上限为 10 份附件，原有体积上限不变。

真实测试应经过业务读取、逐问复核、事实读取、科学审核、方法执行及证书重放。多问题材料要逐问执行并报告遗漏；同一份 A0 可以复用，后续审核及结果必须分别绑定目标。不得把人工补好后的候选算作首答通过。

## 保留的参考脚本

`run_lit_*.py` 保留学生的人工参考构造。这些脚本不代表模型读懂原题；执行时必须明确指定参考模式和仓库之外的新输出目录：

```powershell
python -m evaluation.literature_cases.tools.run_lit_net_04 --reference-fixture --output ../reference_check_new
```

运行不会再重写 public 材料，也不能覆盖已提交的历史记录。旧 structured_runs 原样保留，缺少完整证据的摘要不能直接作为新评分器的通过记录。

## 参考答案与停止原因

- 比较方向是目标的一部分。`POINT_REVERSED_SIGN` 表示目标方向变化，数学状态仍为 POINT。
- 未决定、不采用与真实缺项分别保留。NET-07 的负例明确不采用交换性，不能自动批准它后继续。
- DAG-01 控制中介版：拒绝该调整要求，不等于证明总效应不可识别。完整干预分布的一个函数表达与分别报告两种干预值，需按目标覆盖核对，不能仅数 JSON 条目。
- 有限二元 IV 研究接口已存在；IV-01/02 当前自动入口仍有边界，样本计数也不能当精确总体法则。报告入口未覆盖与缺信息，不能声称证明不可识别。
- NET-02 的公开协议另行提出“组间没有干扰”。历史人工参考没有完整交接该声明，不能据其 POINT 推定同一份公开材料已经通过当前网页入口。真实读取保留该声明而报告适配缺口时，应记录为入口边界；不得删除声明或把它当成读取错误以求通过。
- 论文中的结论、项目自建有限模型的界限、人工参考运行、真实模型运行分别列明。两道 PARTIAL 数值界限不是论文原始数值结果。

## 评分边界

评分器读取冻结输入摘要、逐问结果及独立语义评审。不能只靠“semantic_passed=true”或“point_replay_passed=true”通过。POINT/PARTIAL 需要保存实际执行结果、相应证书与重放记录；PARTIAL 还核对区间与参考值。正确停止必须核对具体原因。

该程序是保存证据的检查器，不是新的万能数学验证器，也不独立理解原文。证书实际重放仍由原识别流程完成。原始回答、首答、格式重试、语义重读、传输失败和人工处理分别统计。

36 份材料可全部作文件与参考一致性检查；模型评测至少覆盖全部 12 个情境。原来的 holdout 标记表示学生建库时的划分，维护者审阅后不能再声称它们是独立盲测。比较可选 Prompt 时，材料、Schema、解析、事实读取和审核保持一致。
