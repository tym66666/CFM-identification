两个固定政策均值之差：有限 D2/E1 mean-box 路线的数学审查
日期：2026-10-23
状态：研究合同与推导。本文本身不表示新路线已实现或已通过代码验收。

一、为什么选择这条第二目标路线

建议在同一个研究、同一背景、同一结果变量和评价权重下，比较两个完整固定政策的总体均值。它直接回答“方案 A 比方案 B 好多少”，并检验框架能否正确处理：比较方向、两份完整安排、共同模型、正负系数、相同签名相消、联合端点见证、目标绑定及完整审核。

这是同一 mean-box 几何的第二种目标路线，不是第二类不同约束几何。完成它不能声称一般 PARTIAL、单调性、DAG 或 IV 已完成。它的优先级高于立即增加更多随机化设计，因为后者主要改变支持计算，未充分检验“同一未知量同时出现在两个目标中”的问题。单调性会增加跨签名耦合，能进一步检验框架，但必须另立科学合同、求解器和验证义务，不能悄悄把它塞进 box 公式。

本轮范围仍建议限定：D2 完全随机化、E1 严格多数且平票为低、固定已知处理前简单无向网络、连续或二元结果、同一评价人群和非负归一化权重、精确总体 A4、全部安排上的均值充分性、显式科学界、无额外耦合。任意有限 n 的数学命题与 n <= 12 的现有穷举软件范围须分开说明。

三、完整模型、信息和目标

固定研究背景 W=w、节点集合 I、处理前网络 G。潜在安排空间为 Z={0,1}^n，两个干预 z^A,z^B 都是完整且具有科学含义的安排。历史设计 q 在 sum_i z_i=m 的所有向量上均匀，其他安排概率为零。

目标保持同一人群：
  Delta = V(z^A)-V(z^B)
        = sum_i omega_i { E[Y_i(z^A)|w]-E[Y_i(z^B)|w] },
  omega_i >= 0, sum_i omega_i=1。
更换评价对象或权重会更换 estimand，不属于同一个问题的假设阶梯。

E1 定义：s_i(z)=(z_i, 1{2 sum_{j in N_i}z_j > |N_i|})。
孤立节点暴露为 0。签名的存在不等于均值充分性成立。

明确前提：
  A. 一致性 Y_i^obs=Y_i(T)，全部潜在结果与完整随机安排 T 条件独立，有限一阶矩，已知 q、固定背景和网络。
  B. 对所有节点、所有 z in Z，有 E[Y_i(z)|w]=h_{i,s_i(z)}。这包括目标支持外安排，不能仅声明在历史支持上成立。
  C. A4 只给清单 J 中精确总体条件均值 b_{i,s}=E[Y_i^obs|s_i(T)=s,w]。每个列出事件的 pi_{i,s}=sum_{z:s_i(z)=s}q(z) 必须大于零。C 与 A、B 合起来推出 h_{i,s}=b_{i,s}。
  D. 对所有签名的条件均值有经审核的节点界 ell_i<=h_{i,s}<=u_i，结果定义、单位、时间、来源和作用范围明确。
  E. 没有额外完整观测分布、聚合等式、跨节点同质性、单调性、平滑性或其他耦合。若实际材料有这些信息，不得丢弃后仍将 box 结果称作该原问题的 sharp 区间。

一个签名坐标 c=(i,a,e) 只在至少一个完整二元安排中出现时才加入有限集合 C。模型可行集合是
  H = { h : h_c=b_c (c in J), ell_i<=h_c<=u_i (c=(i,a,e) in C) }。
全部 A4 值与科学界必须相容，包括与目标无关或目标系数为零的坐标。若有冲突，H 为空，应报告 INCOMPATIBLE，而不是常规识别区间。

连续结果的实现允许声明区间内任意实值。二元结果的 CONDITIONAL_MEAN 界先与 [0,1] 相交；ALMOST_SURE_OUTCOME 界先取 {0,1} 与声明区间的交集，再取其凸包。两者不可互换。例如 E[Y]=1/2 可行，而二元 Y 几乎处处等于 1/2 不可行。

四、先合并同坐标，再处理正负系数

定义每个坐标的净系数
  d_c = sum_i omega_i [ 1{c=(i,s_i(z^A))} - 1{c=(i,s_i(z^B))} ]。
因此 Delta=sum_c d_c h_c。坐标必须含节点 i；不同节点的相同 (a,e) 不可合并，除非另外批准了跨节点同质性。

若某节点两个安排落入同一签名，则该节点贡献严格相消，d_c=0。这是同一个未知量减自身，不能把它当成两个可独立变化的未知均值。相消依赖已批准的均值充分性；撤回 B 后不一定成立。

为维持当前“缺材料阻断”的软件政策，非零净系数坐标若有正设计支持，必须提供精确 A4 数值，否则 NEEDS_INPUT。先相消再应用此规则；不必为已消去的坐标补数值才能计算这个差值，但所有已经提供的 A4 仍须检查，不能因 d_c=0 删除不相容信息。全部目标安排本身仍须完整，不能靠系数相消填补业务文本漏填的政策。

五、界、普遍有效性和完整 sharpness 证明

对 c in J 令 a_c=b_c^*=b_c；对其他坐标令 a_c=ell_i，b_c^*=u_i。这里 b_c^* 是上端点记号，不是新 A4 数据。

定义
  L = sum_{d_c>=0} d_c a_c + sum_{d_c<0} d_c b_c^*，
  U = sum_{d_c>=0} d_c b_c^* + sum_{d_c<0} d_c a_c。

正系数项下界取均值下端点，负系数项下界取均值上端点；上界反过来。不能把单政策非负加权公式原样应用于 signed coefficient。

对任意 h in H，
  Delta-L
   = sum_{d_c>=0} d_c(h_c-a_c)
     +sum_{d_c<0} (-d_c)(b_c^*-h_c) >= 0，
  U-Delta
   = sum_{d_c>=0} d_c(b_c^*-h_c)
     +sum_{d_c<0} (-d_c)(h_c-a_c) >= 0。
已知单元的两端相等，等式余项为零。因此两个界对整个 H 有效。

构造完整均值表：下界世界 h^- 在 d_c>0 的自由坐标取 a_c，在 d_c<0 的自由坐标取 b_c^*，所有已知坐标保留全部 b_c，其他自由坐标取合法中点。上界世界 h^+ 交换这些端点。它们同时满足全部 A4 和所有界，并分别实现 L,U。

这不仅是两个抽象目标端点。对连续结果，可定义 Y_i(z)=h_{i,s_i(z)}；对二元结果，可引入独立于 T 的 U_{i,s}~Uniform(0,1)，定义 Y_i(z)=1{U_{i,s_i(z)}<=h_{i,s_i(z)}}。两者均是完整合法潜在结果模型，满足随机化、一致性和均值充分性，并实现所有声明的 A4 均值。使用更强的逐结果签名结构来构造一个见证，不是把它当作全模型的必要假设。

任意 t in [0,1] 的表 (1-t)h^-+t h^+ 仍在 H 中，并具有合法结果实现，因此每个 (1-t)L+tU 都可达。识别集合恰为闭区间 [L,U]，不只证明两个端点。这里闭性和凸性来自本合同的有限 box 与精确等式；其他路线不能自动继承这一论证。

宽度公式：
  U-L = sum_{c notin J} |d_c| (u_i-ell_i)。
因此 POINT 当且仅当每个非零净系数自由坐标的有效界退化；也包括全部净系数相消的情况。两个政策值各自不是 POINT，差值仍可能 POINT。

六、为什么不能把两个 sharp 区间直接相减

简单反例：同一未知 x in [0,1] 出现在两政策值中，V_A=V_B=x。两个单政策区间均 sharp [0,1]；区间相减得到 [-1,1]，而同一个模型中 V_A-V_B 恒为 0。相减给出了外界，未给 sharp 界。

非平凡可实现反例：四节点，只有边 1--2，节点 3、4 孤立；D2 m=1。只评价节点 1、3，各权重 1/2。政策 A=(1,1,1,0)，B=(1,1,0,0)。节点 1 在两政策中均为签名 (1,1)，历史零支持，未知均值 x in [0,1]；节点 3 的已知总体均值 h_{3,1,0}=3/5、h_{3,0,0}=1/5。因此
  V_A=x/2+3/10，V_B=x/2+1/10，Delta=1/5。
单政策 sharp 界分别为 [3/10,4/5] 与 [1/10,3/5]，直接相减是 [-3/10,7/10]，严格宽于正确识别集 {1/5}。其余已列 A4 单元必须相容，但不改变这个相消事实。

在更强耦合限制下，即使目标坐标不重合，分别取单政策端点也可能无法在同一个世界同时实现。因此“没有共享坐标”只有在已审查的独立 box 几何中才足以保证这种简单组合。

七、同一业务、同一目标、同一 A4 的放宽假设阶梯

固定业务：四名相互合作的销售员两两有联系。历史项目每次在四人中等概率抽取两人使用 AI。评价这同一组四人，在同一期间、同一背景下，“四人全部使用 AI”相对于“四人全部不使用 AI”的平均成交成功概率变化。结果是二元成交成功，权重均为 1/4。

固定网络：K4；固定设计：D2 m=2；固定 E1：严格多数；固定 A4：每个节点的全部正支持签名 (1,0),(0,1) 的精确总体条件均值均为 1/2。这里是用于数学验收的合成总体信息，不是四个样本的估计值。固定目标：z^A=(1,1,1,1)，z^B=(0,0,0,0)。

验证支持：每人有 3 个邻居。历史处理者只有 1 个处理邻居，故为 (1,0)；历史未处理者有 2 个处理邻居，故为 (0,1)。目标 A 的 (1,1)、目标 B 的 (0,0) 都是零支持。两目标不能借历史数据自动点识别。

只更改经独立审核的 CONDITIONAL_MEAN 界，其余问题、设计、A4、均值充分性保持不变：

  层 1：所有节点、所有安排下的均值恰为 1/2。
        有效界 [1/2,1/2]；Delta 的识别集 {0}，POINT。
        这是很强的科学约束强制得到的零效应，不是历史数据自己证明“AI无效”。

  层 2：放宽为所有这些均值在 [1/4,3/4]。
        Delta 的识别集 [-1/2,1/2]，sharp PARTIAL。

  层 3：再撤回额外均值界，只保留二元结果固有范围 [0,1]。
        Delta 的识别集 [-1,1]，仍是 sharp PARTIAL，但没有超过二元结果逻辑范围的信息。

三层可行模型集合满足 H1 subset H2 subset H3，识别集满足 {0} subset [-1/2,1/2] subset [-1,1]。每层均保留全部固定 A4=.5，端点表均可构造为合法二元模型。最强层要求的是均值=.5，绝不是二元结果几乎处处等于 .5。

展示可写“点识别 → 有限 sharp 界 → 仅剩逻辑界（无信息识别）”。不要把最后一层标成无界，也不要标成 UNSUPPORTED。已知二元结果时，差值绝不可能无界。若标签系统只允许 POINT/PARTIAL，则后两层均是 PARTIAL，另行标明是否提供额外信息。

当前 informative 字段的基准尤其要讲清：它比较的是“加上 A4 后的区间”与“本层已声明科学均值界本身给出的区间”，不是跨层固定的 [-1,1]。本例 A4 只落在两个目标之外的签名，因此三层的 informative 都可为 False；层 2 的额外缩窄来自更强科学界。这与层 2 相对初始二元逻辑范围更窄不矛盾。不得为展示效果篡改 informative 的定义。可另展示固定基准、该层假设与区间宽度。

改变界必须生成与当前合同绑定的新审核记录。不能复制上一层“已接受”的审批签名，伪装成所有层均已被人类认可。阶梯是条件分析，不意味着实际业务自动接受三组相互不同的假设。

八、后续更有科学含义的形状限制阶梯（尚未属于 box 入口）

在上述同一个 K4 业务、目标和 A4 下，可以另研究：
  强条件：所有安排反应均值为 1/2 -> Delta=0；
  中条件：只接受关于完整处理向量的逐坐标单调均值反应 -> Delta in [0,1]；
  弱条件：撤回单调性，仅保留均值充分性和二元范围 -> Delta in [-1,1]。

这是数学上可构造的另一嵌套阶梯：对 E1，签名 (0,0) 到 (1,1) 的均值在单调性下有序，历史两个中间签名为 .5。零效应世界全部 .5；最大效应世界两个端点分别 0 和 1、两个中间签名 .5。因此 [0,1] 可达且 sharp。若将单调性规定为逐潜在结果限制，使用同一节点共同 U_i 而非各签名独立 U_{i,s} 可构造满足顺序的 Bernoulli 见证。均值单调性与逐结果单调性应明确区分，不能互相偷换。特别是“所有安排的均值相等”本身不推出逐结果单调；若展示改用逐结果 MTR，强层也必须显式保留该逐结果约束，才有完整潜在结果模型集合的嵌套。

但单调性会耦合至少两个签名，现有“只有各节点独立均值界”的合同不接纳它。需要新约束编译、可行性检验、最优性与端点证书，并重放这些顺序限制。即使某个实例能手算，亦不得把它加入当前 box 求解器的支持声明。该阶梯仅是后续数学路线候选，未被本文标成已实现。

九、撤回均值充分性与撤回均值界是不同操作

若撤回 E[Y_i(z)|w]=h_{i,s_i(z)}，正确未知量应恢复为 mu_{i,z}=E[Y_i(z)|w]。同一 A4 保留下来的约束是
  b_{i,s} = sum_{z:s_i(z)=s} q(z)/pi_{i,s} * mu_{i,z}，
而不是每个这样的 mu_{i,z} 都等于 b_{i,s}。
目标仍为 sum_i omega_i(mu_{i,z^A}-mu_{i,z^B})。原始业务和 A4 没有换，但可行集合变成含聚合等式的不同约束模型。相同签名不再自动相消，需要完整安排坐标上的同一联合求界。支持内只有平均等式不等于每个固定安排的均值已知。

因此撤回 A5 充分性必须走新合同和新证明，不能通过删除一个审查勾选框后继续沿用旧公式。原始样本不确定性、完整联合分布、多来源相容、DAG/IV 也分别需要新信息/模型合同。框架复用的是业务目标绑定、审查、状态区分与证书发布机制，不是强行复用某个特定求界公式。

十、实现前后必须验收的事项

1. 两个完整政策、方向、共同权重、节点顺序、背景、期间、结果定义与信息摘要共同绑定；不可只绑定其中一臂。
2. 独立重放直接枚举全安排，重建两臂签名及合并后的 d_c；不调用生产求解器的净系数或支持引擎。
3. 同时检查全部 A4、科学界、负系数端点、完整见证的两个政策值及差值。负系数不是“负概率”。
4. POINT 包含完全相消、部分相消加精确已知差值、合法退化界；不能强制两臂都 POINT 才准许差值 POINT。
5. 负例至少包括：未知反事实政策、未知评价人群、支持内非零目标缺 A4、未审查/陈旧审查、A4 与界矛盾、额外耦合、方向或第二臂被篡改、重新计算哈希的端点或世界篡改。
6. 一个输入声明的范围、支持与所有模型条件必须先完整审查。不能因差值是零，就跳过问题定义、随机化、A5 或数据相容性门槛。
