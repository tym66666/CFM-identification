- 调用前用私有手写参考确认四份题目可执行：两份 POINT 及证书重放、两份因指定缺项正确停止。参考不发送模型，不计入模型成绩。此预检的固定名额 A0 枚举笔误在任何 API 调用和冻结前已改正，不是运行代码修复。

本轮没有运行代码变更，因此没有再堆新增回归或把上一轮 410 项离线通过计作本轮新测试。既有离线边界验收见[共同规则记录](ASSUMPTION_DEPENDENCY_CONTRACT_ZH.md)，本轮新增证据是四份参考预检及真实全链路执行。
