# 共同定义读取：配置、真实验收与边界

2026-11-03：目标优先 A0 保持 `target-first-skill-1`；固定政策均值和两政策差值的事实读取采用 `network-shared-definitions-1`。推荐起点仍是 `cfm_id.project.start`。这次改善的是读取及阶段交接，不改变数学 Core，也不自动批准科学条件。

## 具体改了什么

- A0 已审核的目标、两端、名单、编码、时期和背景随原文位置传给事实读取；后续仍独立核对是否保留含义。
- 对象、编码、结果和时期在 `study` 集中说明；网络边的证据单列 `network_source_ids`。各条概率、政策、信息和科学声明引用自己的直接主张，不再反复抄写定义来源。
- 工作表显式展示共同定义与直接证据。任一共同定义未审、缺证据或被拒绝，依赖它的执行仍被阻断；程序不补写模型遗漏的引用。
- 两类总体分布使用可读标签，解析时无损映射到原数学接口。空界模型被拒绝，不因结果是计数或二元就创建额外科学模型。
- 局部效应、R3、DAG 保留各自专门事实协议；历史会话继续用原协议重建，不静默切换。

## 真实 API 结果

最终配置先冻结，再对10份新材料运行两个模型。每份包含自然业务问题及分开的研究说明；8份应 POINT，2份应因缺总体信息或一致性未决定而停止。随后保持代码、Skill、材料不变，LongCat 完整重复10题；DeepSeek 另做关闭思考的整组对照。

“完整符合预期”要求首答 A0、事实内容、证据与审核均通过，并且正例实际 POINT 和证书重放通过，或负例因预先指定的缺项正确停止。格式错误或因误读停住不算正确负例。以下没有人工改写原答，也没有复查成功回填首答分数。

| 模型与轮次 | A0 内容及引用审核 | 事实内容及引用审核（实际进入者） | POINT且重放 | 正确缺项阻断 | 完整符合预期 |
|---|---:|---:|---:|---:|---:|
| LongCat-2.5 首轮 | 9/10 | 9/9 | 7/8正例 | 2/2负例 | **9/10** |
| LongCat-2.5 同配置重复 | 8/10 | 8/8 | 7/8正例 | 1/2负例 | **8/10** |
| DeepSeek v4 Flash 开启思考 | 6/10 | 4/6 | 3/8正例 | 1/2负例 | **4/10** |
| DeepSeek v4 Flash 关闭思考对照 | 5/10 | 4/5 | 4/8正例 | 0/2负例 | **4/10** |

LongCat 两轮共17/20次完整通过，但只有10个独立业务，不能称为20道新题。正例两轮均7/8实际识别成功，不是靠缺项题抬高比例。最终范围内用 LongCat 作为本轮已验收配置；DeepSeek 保留可调用和兼容性，**未达到50%的本轮稳定性门槛**，不推荐将其成绩混入 LongCat。

实际传输为 OpenAI 兼容 Chat Completions，JSON object 模式、非流式，最大输出16384 token、300秒超时、无自动重试。LongCat-2.5 使用 `thinking=disabled`；模型调用方须按服务接口提供该参数。项目配置不包含密钥，也不强制用户选定供应商。本轮两组冻结验收及两个对照合计68次真实请求，无传输失败。

之前的开发组另有10个业务：旧候选 DeepSeek 3/10、LongCat 5/10完整通过；更早的[严格逐记录定义引用实验](REVIEWED_INTENT_ACCEPTANCE_ZH.md)完整首答为0/10和1/10。旧失败保留。这些材料、协议不同，不能据此计算严格的配对提升或把几组结果拼成总体准确率。

## 仍然没有解决什么

这些是开发者审核的合成案例，不是独立盲评或整体 NBIB 准确率。真实科学条件必须由研究者确认；本轮批准只针对事先固定的合成方案。材料通过结构化文档接口进入，未测试浏览器上传。

实时覆盖主要为 D1/E1、3至5个单位、固定政策均值及两政策差值，包含全体、子集、单个评价对象，二元和计数结果。没有据此证明 D2–D6、全部暴露、PARTIAL、R3、DAG 的真实读取率。它们的已有接口和数学能力另做离线兼容与重放检查。

LongCat 仍出现 A0 设计字段类型错误、独立抽签误分类、把等权评价当标准化等错误；这些都保留为失败。DeepSeek 还出现政策与背景混写、概率规则误读、编码引用遗漏、额外字段及状态／引用组合错误。JSON Schema 不是语义证明，部分状态组合仍由更严格的本地解析器检查，不能把 Schema 通过等同于可执行。

本次同步标准是：选定配置在受测范围内两轮达到至少50%至60%，同时保留严格审核和数学边界；不是宣称业务理解已无误。工程安装、兼容和三类示例的实际结果另见[交付验收](DELIVERY_READINESS_ZH.md)。
