三、固定问题、总体信息与基础假设
固定有限节点 I、已知处理前简单无向图 G、背景 W=w、二元处理向量 z∈{0,1}^n。
历史设计 q 在恰有 m 个1的向量上均匀，其余为零；m及分配律必须独立审核。
E1签名 s_i(z)=(z_i,e_i(z))，其中
  e_i(z)=1{2 sum_{j∈N_i} z_j > |N_i|}。
平票为低；孤立节点始终 e=0。只保留某个完整安排实际能实现的签名。

固定两个完整政策 zA,zB，同一评价集合、同一非负归一化权重 omega_i：
  Delta = sum_i omega_i [E{Y_i(zA)|w} - E{Y_i(zB)|w}]。
不因想得到更窄区间而改变人群、方向、结果单位或期间。

基础科学合同：
1. 一致性；完整随机分配向量与所有潜在结果独立（给定w）；有限一阶矩。
2. 对所有二元安排，E{Y_i(z)|w}=h_{i,z_i,e_i(z)}。这是均值充分性，包括支持外。
3. A4为显式清单J中的精确总体条件均值，正支持 pi_{i,a,e}>0，且
   b_{i,a,e}=E{Y_i^obs | (T_i,e_i(T))=(a,e),w}。
   前两项才让该总体信息成为 h_{i,a,e}=b_{i,a,e}。
4. 显式、经审核的有效均值界 ell_i<=h_{i,a,e}<=u_i。
   二元结果默认逻辑范围[0,1]仍须与声明的结果类型一致；均值界与几乎处处结果界
   不能互换。连续结果沿用原合同的实值可实现性要求。
5. 除所声明的均值界、精确A4、均值顺序及阶梯明确注明的额外等式外，无其他
   联合分布信息、跨节点限制、聚合方程、IV、平滑性或未建模条件。
   有额外材料时必须适配它或阻断，不能丢弃后宣称对原问题 sharp。

四、必须分开的科学限制
OWN（自身使用非减）：固定其他人的完整安排，只把本人从0改成1，
  E{Y_i(1,z_-i)|w} >= E{Y_i(0,z_-i)|w}。
在E1及均值充分性下等价于每个可实现e：
  h_{i,0,e} <= h_{i,1,e}。

PEERS（同伴使用非减）：固定本人及其他坐标，只把某个邻居从0改成1，
本人的条件均值不下降。等价于对非孤立节点及a=0,1：
  h_{i,a,0} <= h_{i,a,1}。
它允许外溢为零，不要求每次加一个同伴都有严格改善。
非邻居变化在已声明的均值充分性下不改变均值；该结论不是网络连边定义单独给的。

BOTH同时要求OWN和PEERS。非孤立节点有四个未知量，偏序生成边为：
  h00 <= h10；h01 <= h11；h00 <= h01；h10 <= h11。
h10与h01不可自动排序；“本人用且同伴低”与“本人不用且同伴高”不相互支配。
孤立节点只有h00,h10，只保留自身顺序，不能制造不存在的高暴露单元。

必要性：自身切换保持邻居暴露；非孤立节点可选邻居处理数跨过严格多数阈值，
实现由e=0至e=1的一坐标切换，分别保持本人a=0或1。
充分性：E1随每个邻居处理坐标非减；每次一坐标切换只会保持签名或沿上述边移动。
沿有限次切换可得任意完整向量的对应非减结论。
这些推导依赖当前E1。不能把另一暴露定义的标签0/1直接当成顺序。

D2的关键域问题
相同处理人数的不同向量无法逐坐标相互支配；历史设计支持是该偏序的反链。
仅对历史支持中的安排声明坐标单调，不能限制支持外全员推广。
必须明确 ALL_BINARY_ASSIGNMENTS_CONDITIONAL_ON_STUDY_CONTEXT。
目标“固定名额下换人”本身也未必是一个向量增加，不应自动判断效应为非负。

层级区别
条件均值非减比“每次潜在结果都非减”弱。后者还限制潜在结果间的联合关系。
均值非减不等于MTS（跨选择人群的排序），不等于IV不服从者单调性，
也不由随机化、E1定义或“大家觉得AI应该有效”推出。
输入“不会变差”若未说明自身还是同伴、均值还是每次结果、作用对象及范围，
应进入追问/审核；本轮不让LLM自动批准它。

五、联合可行集合、sharp界与实现性
把所有可实现的(i,a,e)排列为向量h；把目标相同坐标系数先合并为d：
  d_{i,a,e}=omega_i [1{s_i(zA)=(a,e)}-1{s_i(zB)=(a,e)}]。
设基础有效界、A4等式和已审核的顺序共同定义
  H_R = {h: ell_i<=h_{i,a,e}<=u_i，h_J=b_J，
              h_c<=h_c' 对每一已声明顺序边(c,c')}。
额外无同伴均值效应仅在明确声明的强层另加 h_{i,a,0}=h_{i,a,1}；
不能把这个等式暗含在OWN或PEERS中。

H_R非空时，它是有限维紧凸多面体。令
  L_R=min_{h∈H_R} d'h，U_R=max_{h∈H_R} d'h。
有效性直接来自同一H_R上的优化。有限界保证极值取得；线性函数在凸集合上的
像是区间。因此每个L_R与U_R之间的值都由一张可行均值表实现。

潜在结果见证不能省略：
- 连续结果：令Y_i(z)=h_{i,s_i(z)}，得到确定性、可实现的完整潜在结果表。
- 二元结果：每个节点取一个独立于分配T的U_i~Uniform(0,1)，所有签名共享它，
  Y_i(z)=1{U_i<=h_{i,s_i(z)}}。
  均值等于h且顺序边上的逐结果关系成立，也满足所有A4均值及随机化/一致性。
  若声明几乎处处二元结果界，先按原合同取{0,1}与该界的交集后取凸包。
这一构造说明每张可行h都对应一个合法模型，从而识别集恰好为[L_R,U_R]。
用更强的逐结果单调见证证明可达，不是在假设中自动加入逐结果单调性。
仅有这些均值约束时，强单调见证足以实现全部可行均值；有完整边际/联合分布等
额外信息时，此结论不能照搬。

H_R为空必须是INCOMPATIBLE；不是PARTIAL，也不是数值求解失败。
只有L_R=U_R才为POINT。均值顺序只是一个可能缩窄可行集合的条件，不保证点识别。

可复用的计算结构
当前约束不跨节点，H_R是各节点小多面体的直积，每块最多四维。
可以分别对每块的有符号目标联合优化，再加总；不能拆成两个政策独立求界再相减。
数学论证适用于任意有限n。未来软件节点上限与穷举重放成本必须单独规定。
研究验算先用有理数顶点枚举，不把浮点求解状态当成证明。

六、未来证书必须多一层“最优性”
两个可行端点世界只证明可达，不能单独证明界外不可能。
把合同独立编译为Ah<=b、Eh=f，所有系数都用规范有理数。
下界证书可采用alpha>=0、自由eta，使
  d = -A'alpha + E'eta，L=-b'alpha + f'eta。
上界采用beta>=0、自由zeta，使
  d = A'beta + E'zeta，U=b'beta + f'zeta。
再检查完整h^-、h^+满足全部约束及d'h^-=L、d'h^+=U。
这些恒等式与非负性证明全域有效，端点证明可达，凸性给整个sharp区间。
也可用完全枚举且覆盖性可独立检查的精确证据，但不能只提供优化器SUCCESS文本。

不相容可用Farkas见证：alpha>=0、A'alpha+E'eta=0，
b'alpha+f'eta<0。没有可靠证据的数值失败应CHECK_BLOCKED，不应冒充INCOMPATIBLE。
正式验证器须从原始study、A4、范围及顺序声明重编译；不接受证书自行宣称的
顺序边、浮点近似最优性、变更后重算的哈希或缺失的非目标A4。
还须核对政策方向、人口权重、所有声明及独立审核来源。

七、同一个直观业务问题的非零假设阶梯
业务：四个互相合作的服务小组准备使用辅助系统，任意两组都有合作关系。
历史每次均匀随机抽两个使用。目标始终是：
“这四个小组全部使用，相比全部不用，平均按时完成任务的概率提高多少？”
四组等权；结果为按时完成=1、否则=0；E1使用严格多数。
这张小图用于可核验例子，数学合同不限定四组或这个业务。

固定的合成总体信息：
每个节点的正支持签名只有(1,0)、(0,1)，精确均值分别为3/5、2/5。
这是独立声明的A4，不是四条样本记录，不是LLM猜测。
全部使用产生(1,1)，全部不用产生(0,0)，两者历史零支持。
问题、网络、处理、分配律、信息和权重在所有层都保持不变。

依次放宽：
A. BOTH + 无同伴均值效应。
   h00=h01=2/5，h10=h11=3/5；POINT {1/5}。
   解释：额外接受“同伴使用不会改变本人的平均结果”，历史两种自身状态足以定出差值。
B. 撤去无同伴均值效应，只保留自身和同伴使用均不降低本人平均结果。
   h00∈[0,2/5]，h11∈[3/5,1]；sharp PARTIAL [1/5,1]。
C. 再撤去同伴非减，只保留自身非减。
   h00∈[0,3/5]，h11∈[2/5,1]；sharp PARTIAL [-1/5,1]。
D. 再撤去自身非减，仅保留基础均值模型、A4和二元范围。
   h00,h11∈[0,1]；sharp PARTIAL [-1,1]，只剩本目标的逻辑范围。

所有节点相同的下/上界世界（按h00,h01,h10,h11排列）：
A：均为(2/5,2/5,3/5,3/5)。
B：下界(2/5,2/5,3/5,3/5)，上界(0,2/5,3/5,1)。
C：下界(3/5,2/5,3/5,2/5)，上界(0,2/5,3/5,1)。
D：下界(1,2/5,3/5,0)，上界(0,2/5,3/5,1)。
每张表满足该层全部条件，且H_A⊂H_B⊂H_C⊂H_D。
最后一层是sharp逻辑界，不是无界，也不是系统UNSUPPORTED。
20个百分点的强层POINT来自信息加科学限制，不能说实验本身已证明20个百分点。
该例PEERS-only与BOTH在给定A4后事实上给出相同可行集合；不能把它们宣传成
每个业务都会严格不同，更不能把“有更多假设”误说成“一定严格缩界”。

第二个固定问题可问“全员使用，相比仅A、B使用，平均改善多少”。
同一K4与A4下，基准政策均值固定为1/2；四层依次为
  {1/10} -> [1/10,1/2] -> [-1/10,1/2] -> [-1/2,1/2]。
在这个问题内部同样保持目标不变。最弱层仍利用了已知基准，不能把所有弱层
都硬写成[-1,1]或完全没有信息。换目标应另建目标摘要，不能混入前题的阶梯。

八、为什么传播单坐标界仍不够
二节点A—B，D2每次选一个，评价A，比较全员使用与全员不用。
A的两个目标签名(1,1)、(0,0)均零支持；只为B提供相容的精确A4。
在BOTH下，A的两政策值各自可在[0,1]内变化，但必须hA00<=hA11。
正确差值界[0,1]；分别求政策值再相减得到[-1,1]，不sharp。
下界可令A各签名相等；上界可令A的h00=0、h11=1，中间签名取合法值。
这里两个目标坐标不同，问题不是重复坐标相消，而是科学限制耦合了它们。
所以给旧box求解器传播一些坐标界后继续独立取端点仍可能出错。

九、边界、审核与未来最小实现
建议新增一个独立MEAN_ORDER约束族，复用现有六个验收hook和共同业务目标绑定；

- 独立可行性检查、精确最优性证据、完整端点世界和重放结果。
最强层no_peer等式本轮仅用于数学阶梯。首个正式版本可只接NONE/OWN/BOTH；
若要发布强层POINT，必须另有显式均值等式合同，不能借展示暗中开启它。

缺材料与数学非识别分别处理：

NEEDS_INPUT”是更严格的软件政策。首版保持该门槛，未改变合同前不得因单调性
可推得某个值就绕过。非目标A4也必须全部检查，不能只取有助于缩界的部分。

预定负例
撤回均值充分性；只在历史支持声明顺序；未指定本人/同伴；结果方向不明；
把“无同伴效应”当成“同伴不会伤害”；A4违反顺序；目标不完整；名单缺失；
缺少审核；旧审核绑定改变后的轴/作用域；额外平滑性或MTS被静默丢弃；
只交可行但非最优端点；篡改dual、A4、权重或方向并重算hash。
上述门槛未逐项实现前，不把研究脚本标成已集成路线。
