# 未声明假设的定义依赖：共同规则与验收

2026-10-31。唯一工作源码为 `autoCFM_Research/research/identification/causal_idfm`，本轮只在本地修改。数学 Core、估计、策略及 System Prompt 均未改动。

## 修复了什么

上轮实际回答把均值充分性标为 `NOT_STATED`，却附上 `definition_refs=["study"]`：公开 Schema 接受，后续定义解析拒绝。本轮把这一字段组合规则收拢到 [policy_assumption_dependencies.py](../cfm_id_llm/policy_assumption_dependencies.py) 的一份规则表。Schema、解析验证、来源审核工作表、诊断和显式重读共同消费它，不自动删字段或补来源。

| 字段状态 | 必须满足的组合 | 不代表什么 |
|---|---|---|
| `NOT_STATED`，原文没有声明 | `source_ids`、`definition_refs`、`covered_nodes` 为空；`scope=UNKNOWN` | 不等于假设成立或已被拒绝 |
| 采用、拟采用、拒绝、未定、冲突 | 必须引用该声明的直接原文 | 有引用不等于科学批准；拟采用和未定不能当作采用 |
| 明确填写覆盖名单 | 必须有 `study` 定义依赖及本声明的直接来源 | 名册只能解释对象，不能证明假设覆盖它们 |
| 使用定义依赖 | 同时必须有直接主张来源 | 定义不能替代科学声明 |

当前实现针对固定政策均值和两政策差值中的 `mean_sufficiency`，复用既有其他科学状态规则。没有宣称已统一任意 DAG、R3 或未来假设类型。

这不要求所有 POINT 都接受均值充分性：例如满足完整处理向量信息和相应科学条件的 R1b，可以在该假设未声明时识别。是否可用仍由原有数学方法及审核判断。

## 接口与兼容

- 显式候选配置为 `network_fact_contract="network-policy-scopes-2"`。主政策、评价范围和比较方向沿用既有合同，不增添新的业务字段。

- 旧协议继续重建原请求和原结果。新规则不追溯改写旧回答，不重新计算上轮成绩。协议标识用于区分请求及审核绑定，维护文件名不带版本后缀。
- 包内推荐配置保持不变。该候选的事实阶段改善不足以证明完整 A0 链路稳定，不自动提升默认。

调用期间 396 个运行文件及 16 个冻结材料／配置等文件保持不变；业务材料与上一轮逐字一致，事实首读 System Prompt 不变。仅请求中的结构化 Schema 增加了共同约束。该小样本结果支持本次接口修复有效，不能据此宣布整体读取已稳定或排名模型。
