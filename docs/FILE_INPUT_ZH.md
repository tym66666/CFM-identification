# 网页文件输入与识别边界

先描述希望比较什么，再按用途上传材料；不要求用户先选择识别方法。个人网页入口是 `python demo/serve.py`。

## 提交什么

| 输入 | 用途与要求 |
|---|---|
| 业务说明与方案 | TXT、MD、JSON、文字PDF、DOCX；描述研究对象、两种情形、结果、时期、实际安排和已有资料。未知或未决定可以直接注明 |
| 字段说明表 | CSV、TSV、XLSX；明确选择工作表和表头行，解释行保留来源。普通表格附件仅提取列名与行数，应将说明表选为对应用途 |
| 对象表 | 一行一个稳定编号，列名 `node_id`；包含没有关系的孤立对象 |
| 关系表 | 一行一条关系，列名 `source,target`；须说明关系含义、时期、是否完整。未列出的关系不自动推定不存在 |
| 有限观测记录 | CSV、TSV、XLSX；选择编号、实际处理、结果、数值特征列和原始处理编码，配套对象表及关系表 |

对象和关系模板可从网页下载。当前关系文件对应固定、简单、无向、无权网络；方向、权重、时间序列不能静默丢弃。对象之间的关系不能自动作为变量DAG中的因果箭头。

数值表按编号关联，不按上传行序猜配对。每个对象一行、单时期、二元处理；未回访对象保留行，结果留空或声明缺失标记。重复或未知编号、多期混杂、公式、缺失特征、未编码类别会拒绝，不自动插补、聚合或删人。Excel编号应保存为文本以保留前导零。

“检查文件读取”完全在本地运行，不需密钥、不调用模型。开始分析时重新校验实际文件。模型只获得字段解释、编号、实际结果覆盖等元数据，不收到逐条测量值。有限记录不能自动成为精确总体均值或分布；识别需要的总体信息和科学条件须另行明确并审核。个人网页没有估计器或Policy依赖。

## 未完整读取时

空文件、截断、无法读取的页或图片会在请求模型前提示处理，不能把文件读取遗漏算作模型已看见。PDF暂无OCR；Word保留正文、表格、脚注、尾注、页眉页脚，但复杂图像、公式和修订不能保证完整恢复。选择一个Excel工作表时，其他表列为未选入，有相关说明须另外上传。

当前单文件最多8MB，表格最多10000条记录、200列，网络最多2000对象；具体识别方法可能有更窄规模或模型限制。上限以内不等于所有问题必能识别。

## 维护与覆盖

| 位置 | 职责 |
|---|---|
| `cfm_id_llm/document_intake.py`、`tabular_files.py` | 文档／表格提取与遗漏说明 |
| `cfm_id_llm/network_files.py`、`network_file_binding.py` | 网络文件校验、来源及模型返回引用的展开 |
| `cfm_id_llm/record_files.py` | 列映射、稳定ID、有限记录覆盖检查 |
| `cfm_id_llm/file_coordinates.py`、`upload_receipt.py` | 确定性的坐标展开与读取回执，不补语义或科学许可 |
| `demo/input-files.js`、`demo/backend/` | 网页上传、本地预览、实际文件复验与识别交接 |
| `demo/tests/test_file_capability_coverage.py` | 全部18个登记方法的文件交接、执行、重放、未审／拒绝阻断 |

当前15个网络方法共享文件入口，涵盖政策均值、两政策差值、局部效应、R3、单臂和有限政策；3个DAG方法共享文档／字典入口，不提供单位网络到变量DAG的转换。具体方法和适用范围见[当前能力](CURRENT_SCOPE_ZH.md)。

覆盖测试使用显式参考候选与合成审核，不能冒充LLM阅读准确率。新增方法必须更新登记及对应样板；方法清单与样板集合不同会报错。输入成功、科学条件采用、数学适用域和证书通过是不同环节。
