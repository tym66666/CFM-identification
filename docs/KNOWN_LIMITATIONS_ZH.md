# 已知限制与下一阶段

更新于 2026-11-08。当前范围以[能力与入口边界](CURRENT_SCOPE_ZH.md)为准；实际发布检查见[收尾记录](RELEASE_ACCEPTANCE_ZH.md)。

| 限制 | 目前做到什么 | 仍需什么 |
|---|---|---|
| 自然语言读取及复核不稳定 | 目标优先 A0、共享定义、来源审核与有界重读已接通 | 单独保留首答和复查成绩；漏读、错分与漏引继续阻断，不追加无界重试 |
| Schema 与语义是两层检查 | 观察性＋未知分配律可合法保留；结果定义一致性规则已贯穿请求、解析和诊断；顺序关系与采用态度的职责已说明 | 格式通过不能代替原文含义正确；未决定不得改成采用，重复备注不能被自动删除 |
| 数学入口与真实模型覆盖不同 | 8 类事实读取、18 个已有方法计划已接共同入口及网页，含局部总效应、单臂、有限政策、观察性效应 | 并非每种家族都已有充分真实正例；新业务仍受各自合同和支持范围限制 |
| 文件输入有明确范围 | 对象表、关系表、字段说明与CSV/Excel记录已接入，按稳定ID和实际覆盖检查；保留来源和未读取内容 | 固定简单无向无权网络、单时期二元处理；暂无OCR、任意图文件、类别编码、插补与面板合并；[详见输入说明](FILE_INPUT_ZH.md) |
| 非采用、未知与真实约束不同 | 可分别记录均值充分性和个体潜在结果充分性；非采用不等于断言为假，必要条件未知仍追问 | 模型仍可能误填字段；真正额外约束不能删除或套用未覆盖定理 |
| 共同诊断视图并非所有路线同构 | 政策均值、两政策、随机化效应、观察性固定背景政策复用公共诊断；其余保留专门证据 | 后续按证据形状适配，不为统一显示复制求解器或许可 |
| PARTIAL 有限 | 当前完整 D2/E1 有限均值模型、明确数值与界限，可加已审均值顺序 | 任意设计、暴露、额外耦合约束不能机械套用；sharp 仅相对于已审模型 |
| 新机制仍需研究 | 后门、调整、单变量经典前门已实现 | IV、一般图 ID、集合／条件前门、更广 PARTIAL、网络与 DAG 联合模型需另做数学合同与独立验证 |
| 研究审核不是生产认证 | 审核绑定内容、版本、目标和来源；网络保留合成研究限制 | 真实身份签名、跨副本撤销、多人协作与生产准入尚未完成 |
| 历史协议与物理布局 | 旧导入、hash 来源 DAG 和研究会话兼容保留；当前推荐配置有唯一入口 | 新开发遵循职责地图，不能认定所有数学文件均已归位或完全单向依赖 |
| 证据的外推边界 | 有离线正负例、真实 API、网页和独立重放记录 | 小样本开发复测不是盲评总体准确率；重放不是 Lean/Coq 形式化证明 |

近期 GPT 接口修复后，前门和均值顺序各取得真实成功，未决定负例正确停止；这些是已知问题的开发复测，不能把此前九题比较改写为 9/9。LongCat 也可能因 A0 格式或字段归属失败，不能用安全阻断冒充正确读取。

历史证据仍见[共同定义读取](SHARED_DEFINITION_ACCEPTANCE_ZH.md)、[均值顺序读取](MEAN_ORDER_READING_CONTRACT_ZH.md)、[R3 签名验收](R3_SIGNATURE_ENTRY_ACCEPTANCE_ZH.md)、[设计／暴露验收](NETWORK_DESIGN_LIVE_ACCEPTANCE_ZH.md)。这些记录描述各自日期、配置和材料，分母不同，不合并计算。

下一阶段优先固定跨模型、未参与调试的完整业务评测，并按错误影响划分：目标／信息／科学条件的关键误读、说明性引用、传输失败和程序异常。只有可复现接口矛盾、审核绕过或数学错误立即修复；模型偶发失败作为限制保留，不为单题不断加长 Prompt。
