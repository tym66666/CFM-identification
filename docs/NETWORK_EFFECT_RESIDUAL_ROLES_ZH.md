# 信息说明与额外条件的归属验收

2026-10-28。接续[样本/总体字段合同验收](NETWORK_EFFECT_INFORMATION_CONTRACT_ZH.md)的首读问题：模型会把已由 information 表达的信息说明再次写入 additional_restrictions，或给原文明示的缺项写说明却不引用原文。

## 本轮修改与边界

运行代码仅修改 `cfm_id_llm/network_effect_reading.py` 的公开读取说明、三个字段描述和请求元数据。`RESIDUAL_ROLES` 统一描述 information、additional_restrictions、unresolved 的职责；同一说明进入字段 Schema 和请求中的 `residual_field_contract`。

按一段话里的各项主张分别判断归属：

- 已由类型、可用性、对象与状态范围完整表达的信息不再复制到额外条件中。
- 同一段同时声明总体均值可用、又给出均值上界时，信息范围进入 information，上界及其适用范围保留在 additional_restrictions。
- 当前 Schema 没有数值位置的具体总体均值、未表达的单调关系、科学条件和方法要求仍须保留；“另有”“补充”“声明”等用词不决定字段归属。
- 原文明说未提供、尚未决定或有冲突时，若写入 unresolved，就引用相应原文；材料完全没提时可以保留空来源，不能编造声明。

这只是读取职责说明，不是自然语言语义验证器。解析器及坐标检查的 AST 未变；答案结构、验证约束、适配器准入、科学审核、数学 Core 和独立重放均未改。程序不自动去重、删限制、补引用或批准条件。原有效回答仍按同一结构解析；请求内容与摘要改变，旧审核不能直接沿用。
