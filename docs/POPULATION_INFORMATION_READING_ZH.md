# 总体信息范围的读取与审核

这项改动只帮助模型准确描述 A4 来源，不增加识别定理，不改变数学 Core，也不认证来源真实性。

业务问题可以很直观，例如“全体门店使用工具后，平均达标率能否确定”。进入识别前，研究材料还必须说明允许使用哪些观测总体信息。不能把用户没写清楚的统计信息自动当成最强信息，也不能因为某条路线只需要均值就丢掉已给出的分布。

## 四个需要分清的方面

| 方面 | 需要读清楚什么 | 不允许的替换 |
|---|---|---|
| 总体或样本 | 符号总体对象、精确总体数值，还是样本/估计 | 样本再大也不能自动变成精确总体信息 |
| 结果变量范围 | 每份分布只含一个对象的结果，还是包含全部结果向量 | 各对象的分布拼在一起不自动给出结果之间的联合依赖 |
| 处理条件范围 | 完整处理向量、本人处理和暴露，还是仅本人处理 | 本人处理不能替代完整名单；已知分配律也不补结果与名单的联合关系 |
| 信息形式与覆盖 | 分布或均值；哪些对象、哪些明确格子 | 不补全未给格子，不从目标评价全体推定来源覆盖全体 |

既有枚举保持原义：

\[
\texttt{NODE\_FULL\_LAW}:
\{P(Y_i^{\rm obs},T\mid W):i\in I\},
\qquad
\texttt{FULL\_JOINT\_LAW}:
P(Y_1^{\rm obs},\ldots,Y_n^{\rm obs},T\mid W).
\]

两者都包含完整处理向量。前者是一族单结果分布，后者还保留全部结果之间的联合依赖。当前完整联合分布原生合同要求覆盖全部研究节点；部分结果向量的联合信息不能冒称此合同。

一个精确反例说明为什么不能拼接：令两个二元结果各自以 1/2 的概率取 1，并与同一完整随机分配向量独立。模型一中两结果总相等，模型二中两结果总相反。两模型的每个 `(Y_i,T)` 分布完全相同，但 `P(Y_1=Y_2)` 分别为 1 和 0。因此逐对象分布不能唯一确定完整联合分布。离线测试用有理数枚举核查了这个例子；它只是信息范围反例，不是本轮新增的因果识别定理。

完整分布在适当支持条件下可由原生模块边际化、条件化以推导所需均值。读取层应保留原始信息，由已有数学规则决定可用的推导。已有来源合同与规则见 [R1b](R1B_VERIFIED_FULL_ASSIGNMENT_POLICY_ZH.md)、[R2](R2_VERIFIED_MEAN_SIGNATURE_POLICY_ZH.md) 和 [A4 支持适配](A4_VERIFIED_SUPPORT_SHADOW_INTEGRATION_ZH.md)；后者是历史范围说明，不能替代当前各路线的验收。

## 代码接入

通用说明在 `cfm_id_llm/information_semantics.py`。它只修改 Prompt 和已有字段的说明文字，输入材料、JSON 字段结构、模型回答、解析器与数学算子都不自动变更。它不包含业务案例编号或按文字强制分类的规则。

```python
from cfm_id import business_intake

session = business_intake.start(
    business_case,
    network_fact_contract="network-source-selections-a4-1",
)
```

这个开发端实验配置复用原文编号格式。旧 `network-source-selections-1` 及默认合同仍可原样重现；切换配置后，旧查询审核和后续事实请求不能继续沿用。显式读取复查保留配置，并对所有字段变化重新审核。它不是要求业务用户选择数学路线。

## 什么情况下需要追问

“每个对象的结果与全部对象处理的联合分布”这种紧凑表述可能被分别理解为逐个对象各有一份分布，或所有结果共同出现在一份分布。参考标签可以记录研究者的原意，但不能仅凭标签认定自然语言完全没有歧义。

适合的澄清是：“材料分别描述每家店的结果与完整名单的关系，还是也描述所有门店结果共同出现的关系？”不应要求业务用户回答内部枚举名。信息范围仍未明确时保留未知，原文解释与科学许可继续独立审核。

模型即使选择了合法字段，也可能解释错误。程序验证来源存在和结构一致，不能证明自然语言蕴含该字段，更不能把一次读取通过当作识别证明。

业务分流现将信息类型或总体/样本性质为 `UNKNOWN` 的候选保留为 `NEEDS_INPUT`，并提示先核对原文，区分原材料缺项与模型漏读。它不再仅因未知就报告识别库未支持。已明确的 `OTHER` 仍保留覆盖缺口；修正未知字段也不会自动删除其他额外限制、释放备注审核或批准科学条件。另一份可用信息不能遮蔽尚未明确的信息，有限有界模型也适用这个检查。

## 本轮验收口径

8 种 A4 材料变体来自两个合成网络业务背景；主要指标检查信息种类、总体/样本性质、结果对象覆盖和明确格子，并单独检查其他读取字段及备注。原始旧措辞被保留作回归，没有为了提高分数直接改写其答案。

DeepSeek 4.1 与 LongCat 使用新旧说明配对；DeepSeek 4 仅验收新说明，因此不能用它声称本轮配对提升。该测试不含真实 A0 调用，也不生成科学批准；不能称作端到端识别准确率。完整记录保存在源码仓库外 `LOCAL_EVIDENCE_NOT_DISTRIBUTED`。默认切换须等待实际结果与独立审核。

后续已另做完整读取链路验收（历史实验记录不随发布分发）：每模型六组固定材料，实际 A0、按来源审核及专门读取后进入原生检查。该批次与上述 A4 配对实验分开；来源重读、独立备注审核、成功识别及失败逐项报告，不能把两批相加成一项准确率。
