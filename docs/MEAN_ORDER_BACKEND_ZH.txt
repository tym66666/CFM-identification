MEAN_ORDER：独立数学后端与离线验收说明
日期：2026-10-24

当前交付是什么
后续进展：已新增显式合成业务审核连接，见 MEAN_ORDER_BUSINESS_ZH.txt；数学后端本身不变。
这是新增的、显式选择的合成数学入口。自然语言阅读与审核由独立的业务接入模块负责。
保留现有 Core、默认路由、Estimation/Policy 及旧证书协议。
当前目标是同一人群、同一非负归一化权重下，两个固定完整政策的均值之差。
完整模型与 sharpness 推导见 MEAN_ORDER_RESEARCH_ZH.txt；这里仅说明软件合同与证据。

适用模型与声明
已知处理前简单无向图，D2 均匀固定名额，E1 严格多数、平票低、孤立节点低。
显式一致性、完整分配向量随机化、有限一阶矩和全安排均值充分性；全部科学
声明不由设计或暴露定义自动推导。A4 仅为列出的正支持签名精确总体均值。
每个节点必须单独声明 NONE / OWN / PEERS / BOTH，方向为结果数值均值非减。
NONE 表示该节点没有额外顺序条件；不表示撤回基础 A5。
逐节点声明不改变节点间无耦合的合同；可以分别声明不同轴，而不必全图相同。
不排序 h10 与 h01。所有顺序及均值充分性作用于所有二元安排，而非仅历史支持。
界必须区分条件均值界与几乎处处结果界；二元结果进一步检查实际可实现性。
有完整联合分布、聚合约束、无同伴效应等式、平滑性或其他限制时，本合同不适配，
不能删除它们后声称得到了原问题的 sharp 界。未知字段、未支持字面值直接阻断。

软件范围是 1–12 个节点，独立重放穷举 2^n 个完整安排；这是验证成本上限，
不是数学定理只能覆盖 12 个节点。当前严格合同要求至少一条 A4；研究脚本中
完全空 A4 的情形尚未接入。目标正支持且合并后的系数非零，却缺 A4 时仍
NEEDS_INPUT，在优化之前停止；不能借单调性推导绕过现有材料门槛。
若同一问题同时缺项且已给条件矛盾，当前先报材料缺项，不承诺一次列出全部问题。

代码入口
- cfm_id/mean_order_contract.py：新严格模型、完整输入绑定、单独合成审核记录。
- cfm_id/mean_order_solver.py：精确有理数求界，输出原始端点与对偶/Farkas证据。
- cfm_id/mean_order_verify.py：从完整安排和一坐标切换独立重建约束并验算证据。
- cfm_id/mean_order.py：prepare / submit；未经审核与显式选择不调用优化器。
- examples/mean_order_fixture.py：独立声明的假想数学案例，不是业务审批工具。
- examples/mean_order_reference.py：复用既有六个验收 hook，不改动原验收框架。
- evaluation/mean_order_acceptance.py：小图全覆盖、冻结研究结果对照、假设阶梯证书。

求解与证明怎样分开
所有约束统一表示为 A h <= b。A4 等式用上下两条不等式表达，不遗漏等式乘子。
每行使用带坐标的语义 ID，例如 bound_lower:["A",0,0]，order:[["A",0,0],["A",1,0]]。
行号或字典顺序不是证据；节点名中的特殊字符由 JSON 编码区分。
求解器利用无跨节点约束，将目标按节点拆成至多四维的联合优化；两个政策共享
同一张均值表，不能先分开求两个均值的界再作区间相减。

每个小多面体的顶点坐标必来自上下界及已知 A4 值的有限锚点集合：若某个
相等坐标连通块未固定在锚点上，有限个非活跃约束有正间隙，可将整块同时
向两个方向作微小扰动，违反顶点定义。枚举这些锚点组合因而包含全部顶点。
此论证仅适用于当前顺序/锚点约束，不推广到任意一般线性约束。
求解器选出极值后，再从活跃约束中寻找非负对偶乘子；找不到证据只能
CHECK_BLOCKED，不能把枚举返回的数当成认证结果。

验证器不枚举求解器的顶点，也不调用它的编译器、计数器或线性代数函数。
它用所有完整处理向量计算 E1 和 D2 支持；用每次一个处理坐标的 0→1 变化
重建获许可的均值顺序，再检查全部 A4、界、非目标节点及目标相消后的坐标。
下界证书 alpha>=0，A'alpha=-d，b'alpha=-L；上界 beta>=0，A'beta=d，b'beta=U。
因此每个可行 h 都满足 L<=d'h<=U。同时完整的 h^-、h^+ 达到两个端点。
凸性给出端点间全部值；二元结果用每节点一个共用 Uniform 构造潜在结果，
连续结果用确定性均值表。该实现性只对所声明的信息模型成立。
这些证明保证 sharpness；仅有两张可行表、优化器 SUCCESS 或正确哈希都不够。

不相容与失败的区别
对当前偏序模型，从任一较大的下界锚点沿顺序路径到较小的上界锚点，构成
不相容证据。把起点的下界约束、路径顺序、终点上界相加，得到 0<=负数。
反之若无这种路径矛盾，各坐标取其所有前驱下界锚点的最大值，即构成可行表。
因此这个检查对当前模型完备；不据此声称能判定任意约束族的不相容。
证书仍用一般的非负组合独立核对 A'gamma=0、b'gamma<0，而不信任路径算法。
二元几乎处处范围若不包含 0 或 1，可实现集合为空，软件用矛盾有效界表示该空集。
INCOMPATIBLE 输出单独 incompatibility_certificate，不发布识别区间。
无可靠证据的异常一律 CHECK_BLOCKED；非法零概率条件均值也是输入合同错误，
不把其数值当作可用 A4。全部断言检查在 python -O 下仍生效。

审核边界
problem_sha256 绑定网络、设计、全部政策、权重、数值信息、顺序轴、作用域和来源。
ReviewedMeanOrder 要求分别确认目标、人群、完整 A4、基础假设、界与顺序；任一
内容改变必须获得新的审核绑定。synthetic_fixture 必须为真，不接受它作为真实业务审批。
solve 是条件数学函数；submit 才检查合成审核。两者的证书都保留
scientific_approval=false、production_admission=false、estimation_handoff_allowed=false。
synthetic_review_checked=true 只表示合成协议审核通过，不表示系统接受了真实科学假设。
后续接业务时，仍需绑定原始材料、实际 LLM 阅读、业务目标和现有独立科学审核。
本轮不能计入 LLM 准确率或自然语言端到端成功率。

验收与结果含义
实际日志与完整证书见源码根目录相对路径：
LOCAL_EVIDENCE_NOT_DISTRIBUTED
tests_gateway/test_mean_order.py 与 test_mean_order_replay.py 包括缺审核/旧审核、
作用域、材料缺项、不可比较签名、非目标矛盾、二元界、负数单位变换、零权重、
孤立节点、固定名额端点、原 mean-box 对照、最优性攻击、Farkas攻击和 -O 检查。
新版六-hook示例只覆盖区间与前置阻断；旧通用框架没有“已证不相容”的专用
hook，Farkas 证据由单独测试验收，不伪造为“根本没有调用后端”的负例。

baseline_bounds_only_range 明确表示只保留有效界、尚未使用 A4 与顺序的范围。
informative_relative_to_bounds_only 是相对于该范围的缩窄，不声称每增加一条
假设都严格缩界；也不把非信息性但 sharp 的有限逻辑区间称作 UNSUPPORTED。

固定 K4 案例验证 BOTH [1/5,1]、OWN [-1/5,1]、NONE [-1,1]，不改变目标与 A4。
原研究阶梯最强层的“无同伴均值效应”仍未接入；不能在展示中把该层 POINT
说成本后端已经提供的新功能。当前另有支持充分或边界 A4 下的 POINT 验收。
