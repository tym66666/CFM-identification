均值顺序：业务材料、独立审核和数学后端的连接
日期：2026-10-24

当前结构
自然语言业务材料
  → 同一次 LLM 阅读分别输出比较目标/原分配事实，以及科学顺序声明
  → 程序核对问题ID、原文来源、对象与条件缺项
  → 独立审核者确认业务含义、各节点各轴，以及完整 A4/A5
  → 检查两侧既有业务/科学审核链
  → 已验收的 mean-order 数学后端
  → 独立原始/对偶证书重放，输出 POINT / sharp PARTIAL / 已证条件不相容。

条件只被提出，不会因 LLM 说出、引用存在或 JSON 合法而被接受。
默认路由、旧 Core、旧数学证书、Estimation/Policy 均未改变。入口仍须显式选择
合成协议；这轮连接的是受控合成业务链，不是无人工审核的真实企业服务。

两个阅读部分为何分开
comparison 沿用既有规则，保留“甲减乙”的方向、完整两端、评价人群与汇总方式。
order_reading 单独报告：适用对象、本人/同伴轴、关系、均值/逐结果层级、安排范围、
是假设声明还是观察描述，以及逐条材料来源。
评价 A 一组，不代表其他组的科学条件可以丢掉。每个模型节点的 OWN、PEERS
都必须明确：提出非减假设，或明确不作该假设。没有说到的轴保持缺项，不能补 NONE。
每个轴先进入 PENDING/CONFIRMED/REJECTED 的独立审核；任一未确认都不能继续识别。
CONFIRMED 对“不作假设”表示确认这个排除决定，并非授予一个不存在的科学许可。

哪些情况要停下
“平均不会变差”未说明谁、改变谁或涵盖哪些安排：NEEDS_INPUT，并给出具体追问。
“原试点中平均表现更好”：观察描述不能代替科学许可，NEEDS_INPUT。
“每次结果都不差”：逐结果限制，不能静默弱化成均值限制，目前 UNSUPPORTED。
“同伴完全没有影响”：等式，不能替换为同伴非减，目前 UNSUPPORTED。
“不提高”、额外平滑性、工具变量、跨节点限制等：标记额外约束，等待专用适配。
伪造/过期来源、模型私带批准字段、科学包覆盖目标、旧审核：CHECK_BLOCKED。
真实的资料缺项、接口格式非法、模型含义未适配、数学不相容是不同状态。
例如比较的第二端仍需保留完整名单，其未知坐标填 null；整个 second=null 属于
现有比较协议的格式错误，保持 CHECK_BLOCKED，不改旧 Core 或偷偷补上名单。

新模块与既有模块怎样连接
cfm_id/mean_order_reading.py：新严格阅读结构、联合请求、原文定位、缺项与未适配检查。
cfm_id/mean_order_business.py：按实际阅读编译目标和 node_orders，绑定新的业务审核。
examples/mean_order_business_fixture.py：生成直观业务说明、独立参考和合成审核；参考不发给 LLM。
tests_gateway/test_mean_order_business.py：同义表达、正负例、来源和既有审核链验收。

ScienceDeclaration 只放独立的模型资料和 study/变量绑定，不允许 first、second、weights、
node_orders 等派生字段。目标来自实际 comparison，顺序来自实际 order_reading；不会用
预填答案代替模型读取。数值 A4、结果界、基础 A5仍是独立科学输入，模型不会猜出它们。
新业务审核绑定完整材料、完整原始候选、精确来源、新科学包、两个端点的旧审核链和
最终数学问题。还需确认每个节点的模式；修改条件、对象、数值或来源必须重新审核。
审核记录是调用方提供的独立合成断言，不是身份认证或数字签名；无权把它当真实审批服务。

未复用旧“无额外耦合”的科学合同
新链直接核对共同 R2 的基础 study、目标、原始分配、全部均值充分性和 A4 来源。
新顺序条件在单独的新合同与审核中扩展；不会把它塞入旧 box 后假称没有额外限制。
原 R2 在支持外不能 POINT，并不阻止明确适配的新 PARTIAL；它的状态只作端点诊断。
只有旧链缺支持或声明的均值覆盖不足这两类允许继续；缺科学审批等错误不能走旁路。
新优化前仍保留“正支持非零目标缺 A4 则阻断”。旧 Core 本身无需学习新顺序定理。

来源与语义不能混淆
来源ID解析只能保证引用的文字确实存在，不能证明该文字支持所填的轴、层级和范围。
离线测试故意把正确来源配错语义，确认独立参考审核拒绝放行，而不是自动修复读取。
来源ID为长哈希：真实调用发现过一个字符抄错。新生成 Schema 将来源字段限定为当前
目录中的枚举，同时继续本地精确解析。不会模糊匹配错误ID、猜测最接近来源或改写回复。

冲突字段的定义
“未发现材料间的明确矛盾”填 false；不代表假设已接受、完整或真实，也无需材料额外
写出“没有矛盾”。明确冲突填 true；材料留下具体未能判定的冲突才填 null。
缺少安排范围，应在 scope 填 UNKNOWN，不能混同为冲突未知。科学待审核亦不是矛盾。
真实初测把这些状态混淆，新增 Prompt 明确区分；检查仍保留 null 阻断，不替模型填 false。
分配事实的冲突与科学顺序的冲突分别判断。
