# 局部网络效应：样本与总体信息的字段合同

2026-10-28。本轮先完成旧运行链与评测的拆分验收，再修复局部效应读取中的字段矛盾。所有变更留在团队仓库的当前本地源码；没有提交、推送或修改数学 Core、适配器准入、独立验证器、Estimation/Policy。

## 修复范围

上一批模型曾把同一份材料写成 `operator=NODE_ARM_MEANS`、`availability=FINITE_SAMPLE` 并列出均值格子。原适配器会阻断，但解析器接受这组相互矛盾的字段；不能把问题全部归因于模型。

新增 `cfm_id_llm/effect_information_rules.py`，统一生成请求 Schema 的组合约束、解析检查和公开复查诊断。Prompt 与字段描述同步说明：

| 原文提供的信息 | 规范化方式 | 执行含义 |
|---|---|---|
| 订单样本、分组样本均值或样本估计 | operator 与 availability 都为 FINITE_SAMPLE；arm_cells 为空；对象范围及来源保留 | 不构成识别所需的总体信息 |
| 明确声明可用的总体条件均值 | NODE_ARM_MEANS，并按原文记录可用性、对象与逐格范围 | 还需独立审核与方法适用检查 |
| 样本与独立声明的总体信息同时存在 | 分别保留两条信息来源；不得互相覆盖 | 样本不否定真实总体声明，也不能补齐其缺少的总体格子 |
| 信息性质或覆盖范围未说明 | 保留 UNKNOWN 或缺项 | 不猜测、不升级、不自动补格 |

只有 NODE_ARM_MEANS 可以有非空 arm_cells。更强总体信息、未知、精确总体值等原有分支仍保留各自状态；本次没有扩大业务适配器的支持域。

字段结构和原协议标识保留；原本有效的样本记录仍有效，矛盾组合现在明确拒绝。请求新增公开组合合同标识并改变摘要，旧请求的审核不能直接沿用。格式诊断定位到整条信息记录，提示两字段关系，不替模型决定哪一项误读；修正须根据原文重新回答、审核全部变化。即使类型相容，把样本错误地称为总体仍须在来源审核中拒绝。

## 显式复查单独报告

冻结首答结束后，选择两个被阻断的正例、一个样本负例和一个缺端负例，再调用 4 次。只发送字段与来源位置、原回答和已有公开复查说明；没有私有参考、替换答案或科学批准。原材料与原 Prompt 保持不变。

四次都恢复完整读取；全部差异分别为 1、1、3、2 项，均重新对照原文审核。其中两个正例得到 POINT 并重放，两个负例保持 NEEDS_INPUT，未调用数学后端。模型移除了重复字段或补上来源，程序未改写任何原始回答。这四次恢复不覆盖 9/16 的首答结果，也不增加独立业务数量。

本轮 6 个首答 POINT 和 2 个复查 POINT 另外以 16/32 个完整安排独立枚举，核对支持概率、带符号系数与合成目标值；潜在结果允许在同一暴露组内变化，没有偷偷加入暴露充分性。枚举数值不作为业务效果估计。
