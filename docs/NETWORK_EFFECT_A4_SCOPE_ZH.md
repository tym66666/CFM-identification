## 这次改什么

明确区分“材料提供什么”与“目标需要什么”。材料明确提供所有对象的四状态均值时，即使只评价一个对象，也要保留原范围；仅提供部分对象或状态时，只记录这一部分，不能补全。符号总体信息虽没有数值，仍有明确的对象和状态坐标。

科学条件未定、背景未确认或存在额外限制，都不允许提前结束对其他材料的读取。这些状态分别保留，已知总体信息仍须完整。有限样本不得升级为总体信息。程序不补格子、不改模型回答、不批准科学条件；本批也未改变回答类型、必填约束或解析器。

## 冻结实验与结果

先冻结说明、源码、材料及评分规则，再调用 LongCat-2.5-Preview。首答实验 18 次：两份旧题的新旧说明对照共 4 次，7 份新材料各重复两次，共 14 次。全部 HTTP 200 并收到 JSON，关闭思考模式、单次上限 300 秒、没有自动重试。JSON 收到不代表满足 Schema。

新材料来自两个完整业务情境：五个园区保洁站沿合作关系调人、四个布草服务点互相支援。使用自然语言业务问题及研究材料，分别评价抽签前固定的三个站等权平均、一个指定服务点。网络为五节点环和四节点星形。改变可用信息或科学条件形成正负例，不算七个独立业务。

所有 A0 均为披露的人工参考，只测试后续事实读取和受控执行；参考答案未发给模型。开发助手逐项对照原文审核，科学许可仅限 `SYNTHETIC_TEST`。这不是完整 LLM 端到端准确率、NBIB 总体准确率或独立盲评。

两份首答失败完整保留：

- `cleaning_missing_arm_1` 把 `additional_restrictions`、`unresolved` 两个字段名放进 information 数组，漏掉必需的两个顶层列表。严格解析拒绝原回答，未自动删字符串或填默认值。
- `linen_sample_2` 保留了 `availability=FINITE_SAMPLE`，但同时写 `operator=NODE_ARM_MEANS` 并列了均值格子。没有把可用性升级为总体信息，原适配器也正确阻断；然而不符合本批有限样本的字段合同，不能算整份正确。目前解析器容许该组合，说明两个字段的职责及组合关系还需进一步澄清，不能全部归因于模型能力。
