# 当前能力与入口边界

更新于 2026-11-06。路径相对 Identification 包根；团队仓库嵌入在 `identification/`，个人仓库直接以此为根。

## 当前入口与配置

新应用使用 `cfm_id.project`，读取配置在 `cfm_id/configuration/reading.json`：A0 为 `target-first-skill-1`，网络事实为 `network-shared-definitions-1`，来源格式为 `short_refs`。实际模型 Skill 分别在 `cfm_id_llm/resources/causal_business_reading/` 和 `network_fact_reading/`。不要按协议编号大小自行切换配置。网页为 R3 等家族显式选用已登记的专门读取配置；旧直接调用的默认值保留兼容。

原问题和材料 → 目标读取 → 意图与来源核对 → 专门事实读取 → A4 信息、A5 科学条件及目标绑定审核 → 定理应用／有限求界 → 独立证书重放。用户无需先选 R1a、R3 或 POINT/PARTIAL；多问题逐问报告，不能用一问成功代表整题。

网页在后台执行读取复核，缺项或科学决定不明确时才追问。后台模型复核不能证明科学条件真实；明确拟采用的条件仍需独立科学确认。详见[框架合同](FRAMEWORK_CONTRACT_ZH.md)。

## 已接通的范围

当前共同登记有 **8 个事实家族、18 个方法计划**，团队和个人 ID 网页均承接此登记。方法数量不是业务成功率。运行事实以 `cfm_id.capability_registry.inventory()` 为准；完整方法名称见[能力登记](CAPABILITY_REGISTRY_ZH.md)。

| 目标 | 当前能力 | 关键边界 |
|---|---|---|
| 一份完整政策的均值 | R1b、R2；有限政策均值界 | 完整政策、评价范围、等权均值及信息明确；R2 另审均值充分性 |
| 两份完整政策的第一端减第二端 | R1b/R2 组合；有限联合差值界；均值顺序联合界 | 保留方向、共同人群／结果／背景；联合界不能用两个独立区间机械相减替代 |
| 随机化局部直接、同伴及局部总效应 | R1a 组合 | 已有 D1–D6/E1–E5 合同；其余安排按原设计条件平均，逐端检查支持 |
| 单个对象、单个局部状态均值 | R1A_RANDOMIZED_ARM | 明确本人和同伴状态；不扩展为任意多对象单臂聚合 |
| 有限份完整政策的加权均值 | R1B_FINITE_POLICY | 权重和全部政策明确，各分量分别检查支持并重放 |
| 观察性固定 W 下完整政策均值 | R3_FULL_ASSIGNMENT / R3_MEAN_SIGNATURE | 最多12对象；完整信息、条件交换性和支持；签名另审全安排均值充分性 |
| 观察性直接／同伴／局部总效应 | R3 条件平均、共同分层、本人与邻居二元特征调整 | 三种信息与交换性合同分别审核；不代表任意高维协变量调整 |
| 变量 DAG 干预分布 | 经典后门、调整、单变量经典前门 | 各自图、潜变量、总体分布及支持合同；不自动合并对象网络和变量 DAG |

R1a/R1b/R2/R3 是识别机制，D1–D6 是分配设计，E1–E5 是暴露定义，三者不是互斥的业务分类。D/E 已接入不意味着任意组合、目标与参数都可点识别。见[设计和暴露入口](NETWORK_DESIGN_EXPOSURE_ENTRY_ZH.md)。

有限网络 PARTIAL 仍限当前 D2/E1、处理前固定简单无向网络、二元处理、精确总体信息、科学界限及完整有限均值模型。均值顺序需逐对象、逐轴声明并独立审核。sharp 仅相对于已审模型；它不是估计置信区间，也不证明现实假设成立。

## 什么仍未解决

- LLM 首答及后台复核仍可能误读、漏引用或不符合 Schema；接口接通不等于自由文本稳定。
- 网络研究执行保留合成审核边界；真实审核者认证、多人撤销和生产准入尚未完成。
- IV、一般潜变量图识别、更广 PARTIAL、网络与 DAG 联合模型未形成完整公共合同。
- 库外建议是独立受控路径，标为 `LLM_UNVERIFIED`，不是网页失败后的自动兜底；没有任意新证明的万能验证器。
- 数学模块保留原物理位置以维持导入和证书兼容；扩展按[开发地图](DEVELOPMENT_ENTRY_ZH.md)区分业务适配与 Core。

## 停止原因与结论

| 情况 | 正确处理 |
|---|---|
| 格式、含义或引用错误 | 保留原答，定位后有界重读，重新审核；不能手改答案后算模型通过 |
| 原文缺项、未决定或冲突 | 追问；新材料使旧审核失效 |
| 拒绝审核、绑定或证书不匹配 | 阻断，不能放行数学结果 |
| 真正超出当前合同 | 报告未覆盖，不冒充不可识别证明 |
| 定理／求界执行且证书重放通过 | 报告 POINT/PARTIAL 等实际结论、公式与采用条件 |

“不采用”“尚未决定”和真实额外约束必须分开；有限记录不能升级为精确总体信息；暴露定义不推出暴露充分性。近期验收与遗留问题见[发布收尾记录](RELEASE_ACCEPTANCE_ZH.md)及[限制清单](KNOWN_LIMITATIONS_ZH.md)。历史小样本成绩保留在各专题验收文档，不汇总成当前整体准确率。
