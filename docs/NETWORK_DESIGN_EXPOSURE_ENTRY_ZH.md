# 已有 D1–D6 / E1–E5 的共同业务接入

工作源码仍为 `autoCFM_Research/research/identification/causal_idfm/`。本轮只补业务字段和原生接口之间的连接，不新增定理、不修改数学 Core；GitHub 发布副本未同步。

## 接好了什么

用户仍只提交业务问题和材料，不需要先选 D、E 或 R。A0 区分研究结构与目标，专门读取保留具体设计和暴露参数；独立审核后，共同转换器调用原有构造器，求解后重放证书。

| 业务目标 | 原生机制 | 本轮接入 |
|---|---|---|
| 同伴状态相同时，本人使用与不使用的差 | R1a 局部均值组合 | D1–D6 × E1–E5，正反方向，固定评价名单 |
| 本人状态相同时，两种同伴状态的差 | R1a 局部均值组合 | D1–D6 × E1–E5，保留多值暴露与比较方向 |
| 一个完整政策的平均结果 | R1b / R2 | 六种原设计；R2 使用五种暴露及独立均值充分性审核 |
| 两个完整政策的平均结果之差 | 同方法的 R1b / R2 有向组合 | 复用上一行，同时检查共同评价范围、结果和背景 |

“接入”表示可以表达、审核并实际调用，**不表示所有参数实例都可点识别**。R1a 每个非零项、R1b 完整政策事件、R2 每个目标签名均由原生后端计算正支持。R2 额外需要对相关对象和全部完整安排成立的均值充分性。原有有限 PARTIAL 仍限 D2/E1 的完整有限模型，不随本轮扩大。

## 分配和暴露分别保留什么

| 分配 | 事实字段 | 不能替代成什么 |
|---|---|---|
| D1 逐对象独立抽签 | 每个对象的已知概率 | 一次实际名单、总体使用比例 |
| D2 全体均匀固定名额 | 固定总名额 | 逐人独立抽签 |
| D3 两组独立均匀固定名额 | 完整不交分组、逐组名额 | 全体均匀固定总名额 |
| D4 独立簇抽签 | 完整固定簇、逐簇概率；簇内一起处理 | 簇内对象独立抽签 |
| D5 多组独立均匀固定名额 | 3–64 个完整不交组及各组名额 | 忽略组限制的分配 |
| D6 两阶段名额混合 | 2–64 个组、1–64 个完整名额向量及其精确联合概率 | 平均名额、各组边际概率或只读第二阶段 |

D6 另有 `first_stage_exclusion`：最终完整处理名单相同时，第一阶段名额方案不再直接影响结果。读取“拟采用／采用”只生成声明；须在科学审核中单独接受。原文未提、尚未决定、明确拒绝或互相矛盾均保留各自状态，不能由抽签规则推定。

| 暴露 | 状态与边界 |
|---|---|
| E1 严格多数 | 0/1；平票及孤立点为 0 |
| E2 三档比例 | 小于 1/3、至少 1/3 但小于 2/3、至少 2/3；0/1/2；孤立点未定义 |
| E3 固定核心同伴的严格多数 | 每个对象须有明确、非空、处理前固定的邻居子集 |
| E4 精确处理邻居人数 | 0 到该对象度数的整数，不压缩为二元值 |
| E5 是否有处理邻居 | 有至少一名为 1，否则 0 |

不完整参数保持缺项；非法划分、越界配额、错误联合概率、非法核心名单或坐标阻断。定义了暴露不等于采用暴露充分性。改变原分配可能改变 R1a 的条件平均目标；固定完整政策的潜在均值目标则不因历史分配变化而变成另一个目标。

A0 的类别比事实层粗：分组用 `STRATIFIED_FIXED_QUOTAS`，簇用 `CLUSTER_RANDOMIZATION`，尚无专名的两阶段设计可用 `OTHER` 并保留完整机制。A0 的 `OTHER` 不自动等于数学库未覆盖；后续事实读取仍须对照原文与自身 schema，区分 D3/D5/D6。不会根据粗类别补造参数。

## 如何复现

```powershell
python -m pytest tests_gateway/test_network_design_entry.py -q
python -m examples.network_design_exposure_reference --allow-synthetic-reviews --output outputs/design_exposure
```

例程会运行 30 个设计/暴露组合，每个组合四类目标，共 120 个离线执行案例，输出状态和重放摘要。目录需尚不存在。原始材料、固定参考和合成审核由示例代码明确构造，没有真实 LLM 调用，不能据此报告自然语言准确率。

定向测试还用独立的六节点全枚举分配规律对照 R1a 每一端的联合支持与组合系数，包含异质概率、簇内相关和不等权两阶段混合；不调用生产支持函数生成参考。旧接口及原生数学回归另外运行。库外 LLM、IV、新 PARTIAL、非等权业务目标、独立单个局部均值等不在本轮接入范围。

## 本轮实际验收（2026-10-31）

- 本文件对应的接入验收共 78 项；其中 30 项分别对应 30 个 D/E 组合，每项执行四类目标，合计 120 个执行案例，均得到 POINT 并独立重放。另用 `project.start` 加载当前唯一推荐配置，对 D6/E3 的四类目标完成逐字段、来源、科学审核和实际重放。
- 单政策与差值在全部 14 个已登记读取配置下保留新参数；局部角色/定义依赖/覆盖协议保持兼容。D6 缺条件、未决定、否定、冲突、科学审核遗漏/拒绝、来源拒绝、过期审核、非法参数与零支持分别检查。
- 先完成 364 项旧入口及共同合同回归。随后扩大检查，在本轮最终运行代码上完成 338 项测试和 317 个子检查；其中 1 项 300 节点原生测试最初因 Windows 沙箱临时目录权限失败，将 `tempfile.tempdir` 指向工作目录内 `.pytest_cache` 后单独重跑通过。随后新增的推荐公共入口测试也通过，因此这组共 339 个不同测试通过；这与先前 364 项有交集，不相加报告。
