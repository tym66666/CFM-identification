# 四类读取问题：修复、审核与发布边界

本框架提供的是需要独立审核的识别链路。Schema 合法不等于业务含义正确；证书验证的是提交的数学问题，不能代替原文语义审核。下面区分程序已检查的内容与仍由审核者核对的内容，不把安全阻断算作业务读取成功。

| 问题 | 当前处理 | 尚未解决的能力 |
|---|---|---|
| Schema 允许、本地拒绝 | 均值顺序 NOT_ASSUMED 的 level/scope 必须为 null；公开 Schema、解析、诊断和复查共用规则。旧协议不偷偷迁移。 | 不保证任意跨字段科学含义都能由 JSON Schema 判定。 |
| 总体均值写进样本字段；比较方向读反 | 样本资料与 A4 总体信息分别审核。目标两端与运算方向分别保留；拒绝字段审核就不能继续；改变目标后旧审核和证书失效。 | 对自然语言原句的语义错误仍需独立审核；程序不会仅凭关键词自动判对或改正。 |
| 名单、作用域引用漏填 | 每条声明保留自己的实际引用。审核表展示原文与字段；引用不全被拒绝后阻断，不用父字段或审核人的引用替模型补齐。 | 非空且存在的引用也可能不足以支持整条声明，这不是纯格式检查能够保证的。 |
| 顺序条件又填入额外约束 | 已有顺序由 order_reading 承担；真实额外限制必须保留。重复登记由字段职责审核拒绝后重读；未获确认时保守停止，不删除条件。 | 尚无可靠的通用自然语言等价判断器，不能自动把相似两句话合并。 |

这些处理没有自动批准科学条件。它们也没有把模型答案改成参考答案：原答、复查答复和变更审核分别保留，重新审核完成前不能复用旧批准。

## 三种科学状态

- **未决定**：UNKNOWN；保留缺项，继续追问，不能改成“不采用”。
- **明确不采用**：NOT_ASSUMED；该轴没有顺序许可，不等于结果不受影响，也不等于采用相反顺序。
- **采用额外限制**：保存限制及来源。当前适配器未覆盖时报告 ADAPTER_NOT_CONNECTED，不能据此宣称数学不可识别。

“除已声明条件外没有其他约束”是单独的完整性声明，不是额外限制；某条顺序未决定，不自动替它作真假判断。完整规则见[均值顺序读取合同](MEAN_ORDER_READING_CONTRACT_ZH.md)。

## 可以复现哪些保证

运行 `python -m pytest -q tests_gateway/test_mean_order_field_contract.py tests_gateway/test_network_mean_order_dispatch.py`，检查公开／本地合同一致、未决定与不采用的区别、额外约束保留、审核拒绝、假设阶梯和证书重放。前者已加入固定框架 full；quick 包含组合规则，chain 包含完整新合同检查。

其他现有检查继续覆盖 A0 字段拒绝（`test_business_field_review.py`）、比较方向及联合目标（`test_network_contrast_dispatch.py`）、有限样本不冒充总体信息（`test_network_dispatch.py`）和逐记录来源审核（`test_fact_source_review.py`）。这些是确定性程序与审核边界测试，不是语义自动识别准确率。
