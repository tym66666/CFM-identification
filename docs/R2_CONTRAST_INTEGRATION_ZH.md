# 已有 R2 两政策差值接入与验收

2026-10-30。本轮只连接已有数学能力，不修改 Prompt、科学审核要求或数学 Core，不调用 API，代码仅保存在团队仓库本地。

## 补上的业务缺口

六家有合作关系的门诊，原试点每轮恰好抽取三家使用排班工具。现在问：“全部使用相比全部不使用，六家门诊本周每天准时开诊的比例增加多少？”

完整的全用、全不用安排在原设计下均不出现，因此 R1b 不直接识别这两个完整安排。但本例六节点环图中，两端各节点所需的自身处理／同伴状态都有正支持。在已审核的全安排均值充分性及相应符号总体信息下，原生 R2 可以分别识别两端。系统现在将两个已验证的均值按所问方向相减，给出差值识别式。

另一个完整业务为五仓合作线路，评价其中两仓的平均配载分钟数；用它检查指定子集与连续结果。原文、设计、科学声明和参考读取放在 `examples/network_r2_contrast_reference.py`。这些是离线合成业务参考，不是模型回答或真实科学批准。

## 连接位置与证明边界

| 环节 | 本轮处理 |
|---|---|
| 共同意图与比较事实读取 | 原有合同不变，仍保留两端完整安排、共同人群及有向相减 |
| 方法登记 | 在现有 `NETWORK_POLICY_CONTRAST_FACTS` 下增加 `R2_ENDPOINT_DIFFERENCE`，不增加用户菜单或一套 Prompt |
| 计划与科学审核 | 复用单政策 R2 的 A4/A5；所有拟调用方法的审核先完成，才编译或调用数学后端 |
| 单端计算与证书 | 原生 `identification_business` 和 `identification_policy_r2`，逐端重放，核对返回目标与已审输入 |
| 差值组合 | `cfm_id/workflows/policy_difference.py`；两端须同研究、同 A4/A5、同签名与充分性；绑定外部目标、名单、权重及相减方向 |
| 组合核对 | 重新从外部目标权重与已重放的节点证据构造正负项，核对公式、摘要和范围；不是一个新的 R2 定理或形式化证明助手 |
| 结果 | 一个原问题、一份差值结果，保留两端原生证据及组合记录；不交接数值估计或策略 |

完整数学合同见 [R2 差值合同](R2_POLICY_DIFFERENCE_CONTRACT_ZH.md)。不能从两个单独区间机械相减声称 sharp；本轮没有改动联合 PARTIAL 后端。
