# 分类与文献依据

维护日期：2026-11-11。本文是分类来源与维护决策，不是新数学定理、能力登记或测试成绩。可执行范围仍以 `cfm_id.capability_registry.inventory()` 为准。对应的机器可读导航为 [classification_map.json](classification_map.json)，文献阅读范围见 [catalog.json](catalog.json)。

## 先区分四种依据

1. **综述概括的研究维度**：用来发现问题空间，不直接证明某条业务路线。
2. **原始论文或专著中的方法/定理**：必须核对其目标、总体信息、模型、支持条件与我们的合同是否一致。
3. **项目对已有原理的特化或组合**：完整推导维护在项目数学文档，不能冒称论文逐字给出或数学创新。
4. **工程组织**：字段、读取家族、审核阶段、任务分工。可以有方法论依据，但不需要伪造一篇“认证了项目目录结构”的文献。

本次主要综述起点是 Bhadra–Schweinberger 的 [Causal Inference Under Network Interference，指定 v2](https://arxiv.org/html/2508.06808v2)：本次核对目录、摘要和实验/观测等选定内容，不声称全文证明复核。另补已发表综述 Halloran–Hudgens 的 [Dependent Happenings](https://pubmed.ncbi.nlm.nih.gov/28133589/)；目前只核对题录、摘要和索引片段，供学生继续读正文。后者是本轮补充，不能倒写成项目早期设计已使用的来源。

|---|---|---|---|
| R1a | 原设计下的局部 arm 均值及线性组合 | Aronow–Samii；Sävje；Hudgens–Halloran | 这里 g 用于目标分组，不能默加 exposure sufficiency；见 [R1a 映射](routes/network_r1a.json) |

| R3 观测律标准化 | p 是因果目标中的平均权重 | 目标平均方式、暴露定义及交换性的文献背景 | 不是控制其他对象处理不变的直接效应；见 [标准化映射](routes/network_r3_standardization.json) |

### 路线之间如何区分与重叠

R1a、R1b、R2、R3 是项目内部的兼容编号。阅读这些路线时，可以先看目标是什么，再看处理如何分配，以及识别要依赖哪些假设。同一问题可能满足多条路线的条件。

- **R1a 问的是：给定本人处理与同伴暴露状态，按原实验设计加权后的平均结果。** 对一个研究对象，把产生同一本人处理和同伴暴露状态的完整安排，按设计在该状态内的条件概率加权平均。这个目标允许同一状态对应的不同完整安排产生不同结果。
- **R1b 和 R2 问的是指定完整安排的政策均值。** R1b 直接使用目标安排对应的总体条件均值，要求该完整安排在实验中有正概率。R2 按节点使用目标签名，额外假定在给定背景下，同一节点在本人处理和暴露签名相同的安排中具有相同的潜在结果均值。这样，即使目标完整安排的概率为零，只要各正权重节点的目标签名有正支持、总体信息充分，仍可识别该政策值。
- **R3 区分观测研究中的不同识别论证。** 对固定政策，Full 使用目标完整安排的正观测支持及其条件均值。Signature 还需要均值签名充分性，并检查各正权重节点的目标签名是否有正观测支持。两者都要求在给定处理前背景后，完整处理向量与潜在结果满足条件交换性。R3 还包括表中另列的标准化和暴露调整路线。

例如，在同一随机实验中，若目标完整安排有正支持、均值签名充分性成立，且两条路线所需的总体信息都具备，R1b 和 R2 会识别同一个政策均值。完整安排的正支持会带来各节点目标签名的正支持。反过来，各节点的目标签名可以分别由不同安排实现，目标完整安排本身仍可能从未被该设计抽到。

推导、反例与审查状态见[分类审查报告](../docs/math_audit/classification_review.md)。当前软件覆盖见[能力说明](../docs/CURRENT_SCOPE_ZH.md)和[能力登记](../cfm_id/capability_registry.py)。

## D 与 E：有依据的组件，非标准的编号目录

| 当前 D | 精确含义 |
|---|---|
| D1 | 对象级独立 Bernoulli，概率可异质 |
| D2 | 均匀固定总名额的完全随机化 |
| D3 | 两组分别固定名额 |
| D4 | 固定分簇、簇级独立 Bernoulli，簇内同处理 |
| D5 | 多组分别固定名额；D3 是其双组特例 |
| D6 | 指定有限配额组合的两阶段随机混合；不等于所有两阶段设计 |

Bernoulli/完全随机化/簇随机化有综述背景；两阶段设计有 Hudgens–Halloran 等参照。**D3/D5 的分开主要是历史接口，D6 的有限实现是项目限制**。无需寻找文献证明它们必须恰好分成六类。实现位置：[assignment.py](../pfn_pipeline/_internal/identification/randomized_arm_family/assignment.py)。

| 当前 E | 精确含义 |
|---|---|
| E1 | 全邻居严格多数；平票为低 |
| E2 | 邻居处理比例三档；当前阈值为 1/3、2/3，孤立节点该比例未定义 |
| E3 | 处理前指定核心合作者集合上的严格多数 |
| E4 | 已处理邻居的精确人数 |
| E5 | 是否至少有一个已处理邻居 |

Exposure mapping 是文献支持的抽象；**这些阈值、参考集合、孤立节点约定是具体合同**。E3 还混合了“参考谁”与“如何汇总”两个维度，未来若多次扩展可拆为组件，当前不为了分类整齐重写 Core。实现位置：[exposure.py](../pfn_pipeline/_internal/identification/randomized_arm_family/exposure.py)。任何 E 都不能自动批准均值/个体结果充分性；E 更粗也不自动获得合法 POINT。

## A0–A6 和识别集合的合理性

项目需要分别保存目标 Q、模型限制 M、可用信息 O。相容模型集合非空时，识别集合为：

\[
\Gamma(o)=\{Q(M):M\in\mathcal M_A,\ O(M)=o\}.
\]

这个组织有 [Duarte 等的离散识别研究](https://arxiv.org/abs/2109.13471)等方法论依据，图识别也分别给定图、观察分布与目标；但 **A0–A6 的编号及字段是项目方案**。当前有限均值模型不是 Duarte 的通用多项式优化器。

同一 Q 与 O 下，若明确删除限制使 \(\mathcal M_{A_s}\subseteq\mathcal M_{A_w}\)，则 \(\Gamma_s(o)\subseteq\Gamma_w(o)\)。区间可以变宽，也可能不变；不能保证每次都出现 POINT→PARTIAL。删掉业务原文中的一句话可能只造成“未确认”，与科学上明确撤回假设不同。空相容集合是模型/信息不相容，不是零宽度 POINT。

sharp 界不等于有限样本置信区间。只验证上下端点最优性未必证明任意模型的识别集合是一个区间；当前凸有限均值模型有相应结构，新模型须另证。
