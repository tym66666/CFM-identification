# LIT-DAG-02 来源卡：Pearl (1995) 前门准则

## 1. 文献信息

- Pearl, J. (1995). *Causal Diagrams for Empirical Research*. *Biometrika* 82(4):669–688. DOI: 10.1093/biomet/82.4.669。
- 核对位置：§3.2 前门准则、Theorem 2、式 (9)；作者公开稿 `R218-B.pdf`。

## 2. 案例与论文的关系

本案例是经典前门图的二元教学改编：

- 吸烟 \(X\)；
- 焦油沉积 \(Z\)；
- 肺癌 \(Y\)；
- 未观测的体质因素 \(U\) 同时影响吸烟和肺癌；
- 没有吸烟到肺癌的直接边。

目标：

\[
p(y\mid do(x)).
\]

前门公式：

\[
p(y\mid do(x))
=
\sum_z p(z\mid x)\sum_{x'}p(y\mid x',z)p(x').
\]

## 3. 论文支撑什么 / 不支撑什么

支撑：

- 前门准则的图形条件；
- 中介截住全部有向路径；
- 处理到中介无后门、中介到结果的后门由处理阻断；
- 式 (9) 的内层 \(x'\) 与外层干预 \(x\) 不同。

不支撑：

- 不支撑把合成图当作现实医学事实；
- 不支撑没有中介完整性时继续用前门公式；
- 不支撑把前门当作一般图 ID 的完备算法。
