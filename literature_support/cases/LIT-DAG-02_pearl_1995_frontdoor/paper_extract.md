# 原文摘录与边界：Pearl (1995) 前门准则

## 1. 本案例实际用到的原文位置

- §3.2 前门准则；
- Theorem 2；
- 式 (9)。

## 2. 前门公式

\[
p(y\mid do(x))
=
\sum_z p(z\mid x)
\sum_{x'} p(y\mid x',z)p(x').
\]

其中：

- 外层 \(x\) 是干预值；
- 内层 \(x'\) 是求和的另一个处理值；
- \(z\) 是中介；
- 不能把内层 \(x'\) 误写成外层 \(x\)。

## 3. 三条图形条件

1. 中介 \(Z\) 截住 \(X\) 到 \(Y\) 的全部有向路径；
2. \(X\) 到 \(Z\) 没有后门路径；
3. \(Z\) 到 \(Y\) 的后门路径由 \(X\) 阻断。

本案例的图：

```text
U → X
U → Y
X → Z
Z → Y
```

\(U\) 未观测；没有 \(X\to Y\) 直接边。

## 4. 不支撑

- 不支撑没有中介完整性时继续用前门公式；
- 不支撑把合成图当作医学事实；
- 不支撑把前门当作一般 ID 完备算法。
